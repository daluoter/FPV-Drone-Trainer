## 自己練習

按「開始課程」，倒數後保持低油門、明確 Arm，再緩慢加油門離地。接近目標環高度時提早降低上升速度，用小量 Roll／Pitch 減少水平漂移；回到接近水平後，再用小量油門維持高度。

| 步驟 | 完成重點 |
| --- | --- |
| 起飛前準備 | 在起飛墊附近的低高度、低速度與水平姿態開始。 |
| 垂直離地 | 實際離開起飛區並受控上升，不能從高空跳過起飛。 |
| 定點懸停 1.5 秒 | 在起飛參考點上方 2 m 的目標附近，同時保持位置、高度、低速度與低傾角，連續維持 1.5 秒。 |

只碰到目標高度不算懸停；漂移或升降速度尚未收斂，連續確認時間會重計。Acro 搖桿回中不會自動回平或煞停，需觀察姿態與移動方向再修正。看見完成結果即可 Disarm，下一課是 **L02 起飛與直線穿圈**。
