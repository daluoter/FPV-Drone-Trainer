# L20 騎牆：試用與驗收

目前版本：**2026.11.13.2**。課程 ID：`wall-ride`，規則 **7**。使用者已確認「機腹朝牆、保留間隙貼牆飛行，理論上不應碰牆」，並於 2026-11-13 授權開發。**L20 人工操控驗收仍待回覆**。L01～L15、L17～L19、自由鏡頭及飛行畫面全螢幕的既有人工核准保留；L16 倒刷鍋繼續暫緩人工驗證。設備校正與調參中文介面的術語已核准，介面人工驗收仍獨立追蹤。

本課練習「地面自行起飛 → 靠近右側牆面前端 → 帶速進場 → 側傾讓機腹朝牆 → 保留間隙沿牆前飛 → 回正離牆 → 恢復控制」。牆面是實體障礙，不能穿過或擦碰；機腹朝向與沿牆位移必須同時成立。

## 入口與第一輪練法

1. 更新本機、重新整理，確認頁首為 **2026.11.13.2**；若使用預覽模式，先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)。不必清除舊成績。
2. 在「選擇課程」選 **L20 騎牆**，先觀看 **L20 騎牆示範**。示範預設半速，有獨立八步與章節；連續騎牆段實際約 2.35 秒，半速觀看約 4.7 秒，末幀應為 **8／8**。
3. 可先暫停並用 Chase／Free / debug 看清牆面、藍色進場區、沿牆方向及向外離牆的路線。牆位於起飛方向的右前方；−Z 是前方、＋X 是右方。
4. 按「結束示範／回到練習」，選不限時引導練習並按「開始課程」。倒數後保持低油門，自行按 **Arm** 明確解鎖，由地面起飛至約 **60 m**，保留較長側傾段自然下沉及改出的空間。
5. 從牆面前端進場，先沿牆向前移動至少 **2 m**，再讓機腹朝向牆面；沿牆方向是持續向前，無須停住或懸停。
6. 在容許距離與高度內，保持機腹朝牆，連續沿牆前飛至少 **16 m，且持續至少 2 秒**。不需要精準側立 90° 或等高；可看畫面中的距牆、朝牆偏差與本段距離。
7. 等沿牆步驟完成後回正、向外離牆，再減緩升降與旋轉，確認 **0.2 秒**。保持前進也能完成，不要求停住或降落。

全螢幕入口在飛行視窗右上角；只放大飛行畫面時仍保留高度／XYZ 與騎牆儀表。要操作示範章節、選課或其他面板，先按 Esc 或「離開全螢幕」返回。

## 場景與目前容許範圍

| 項目 | 設定 |
| --- | --- |
| 實體牆 | 右側可見面在起飛點 X＋10 m；牆長 40 m、高 72 m、厚 1 m。 |
| 牆面前後範圍 | 起飛點前方 12～52 m，保留進場及向外改出空間。 |
| 建議練習高度 | 離地約 60 m；起飛里程碑至少離地 3 m。 |
| 進場 | 機體中心距牆 0.8～7 m、離地 3～68 m，在牆前端附近建立至少 2 m 的實際前進。 |
| 騎牆段 | 機體中心距牆 0.8～5 m、離地 3～68 m，沿實際牆面範圍內向前飛行。 |
| 機腹朝向 | 機腹朝牆偏差 45° 內；0° 是機腹正對牆面，這不是橫滾角度。 |
| 沿牆完成 | 同一段連續合格路線，前進淨距離至少 16 m，持續至少 2 秒。 |
| 向外離牆 | 中心距牆至少 5.5 m，且比沿牆完成時再增加至少 1 m。 |
| 恢復控制 | 離牆後保持空中正飛、降低殘餘升降與旋轉，連續確認 0.2 秒。 |

40 m 是可見牆長，不要求飛完整面牆；四個引導點與路徑提供參考，不必精準逐點通過。當儀表與第六步確認本段 16 m 及 2 秒完成後，即可離牆改出，不用追到遠端標記。路徑約由 60 m 下降至 32 m、17 m，協助預留自然下沉及改出空間；不用追求等高或精準通過引導點。上述是本專案目前教學參數，仍待人工試飛校準，不代表真機建議距離。距牆數字量的是機體中心；實際碰撞使用保守全機包絡，仍須為機體及槳保留空間。

進場區約在牆前端前後，無須精準穿過一個小點。恢復階段容許傾角 50° 內、機身角速度 220°/s 內、升降速度 ±8 m/s、水平速度 30 m/s 內，且離地至少 1 m。引導練習不限時，能力挑戰為 300 秒。

## 八步進度

| 步驟 | 觀察重點 |
| --- | --- |
| 1 地面開始 | 起飛區實際接地，低油門明確解鎖。 |
| 2 自行起飛 | 自行取得高度，建議約 60 m。 |
| 3 靠近牆面前端 | 由藍色進場區靠近，保留間隙。 |
| 4 建立沿牆前進 | 進場後實際沿牆前進至少 2 m。 |
| 5 側傾讓機腹朝牆 | 在牆面旁讓機腹朝向牆面，準備掠飛。 |
| 6 保留間隙沿牆前進 | 姿態、距牆與實際前進同時符合，連續完成至少 16 m 且持續 2 秒。 |
| 7 向外離開牆面 | 擴大間隙，離開騎牆路段。 |
| 8 回正並恢復控制 | 減緩升降與旋轉，空中回正確認 0.2 秒。 |

一般正飛平行牆面、只把機頭轉向牆、原地側傾或只操作鏡頭，都不能完成騎牆。機腹朝牆與沿牆距離使用實際飛機姿態及連續路線，不以打桿腳本或字幕時間當作通關。

## 儀表與重試

畫面保留高度／XYZ，另顯示八步階段、機體中心距牆、機腹朝牆偏差、本段沿牆距離／時間及前進速度。朝牆偏差越小，機腹越朝向牆面；不要把它誤讀成機身側傾角。沿牆路段完成後，距牆與角度繼續顯示目前值；回正離牆時可大於騎牆段的 5 m／45°，此時目標已改為拉開間隙及恢復控制。

本段開始後，離開距牆／高度／姿態範圍、越過牆面範圍或明顯回頭時，會保存**第一個中斷原因及當時數值**。尚未墜毀可先回到牆面前端之前重新進場：須至少在前端前方 2 m，即回到起飛點前方 10 m 以內（相對 Z ≥ −10 m）；重新建立進場、機腹朝牆及完整沿牆路段。先前勾選保留為教學里程碑，但本段距離與時間會重新建立，不能把中斷前後片段拼成完成。

碰牆、墜毀、上鎖或資料中斷時，依提示停止並按「再練一次」／重設，重新從地面解鎖。先帶前進速度再側傾；速度較慢時會在側傾中停留較久、下沉更多，須保留改出高度，但判定沒有隱藏最低速度。側傾會減少向上的推力，本課沒有吸附牆面、自動定高、自動回正或額外推力。

## 示範與紀錄

獨立示範以正常 RC 輸入、相同飛控及物理錄製，使用同一面牆的碰撞盒；只在開始時重設到地面，之後不覆寫空中姿態、位置或速度。新版提高進場高度，實際示範側傾後與末幀仍留約 12 m 離地餘裕；這是示範觀察值，不是額外真人通關門檻。它只生成錄影，不接管真人飛行。

八步、字幕、桿量、飛機與數值共用播放時間。按章節會暫停在當時的觀察狀態，倒退會還原尚未完成的距離與步驟；觀看、暫停、重播、換鏡頭及退出都不新增真人成績。真人沿用 `wall-ride` ID，規則升為 **7**。舊規則 6 的短程成績與原始資料保留為歷史，不會直接完成加長版；其他已核准課程的 ID、規則、原始成績與偏好保留，L19 或 L18 完成也不能直接完成 L20。

## 人工核對清單

1. 版本 **2026.11.13.2** 及入口能找到 **L20 騎牆**與其示範，舊選課與成績保留；舊規則 6 不直接完成新版規則 7。
2. 示範由地面起飛，機腹朝牆時牆面在 FPV 中呈現像地面的效果；有真正沿牆位移，騎牆段比前版更長、同時完成至少 16 m 及 2 秒，結尾完成 **8／8**。
3. 牆面、進場、沿牆與離牆方向清楚；Chase／Free 可看清機腹與牆面的關係。
4. 半速、暫停、章節及倒退時，步驟、機體、桿量與儀表一致，觀看不新增成績。
5. 自行從地面起飛至約 60 m，完成一次保留間隙的騎牆與離牆，不必精準等高、側立 90° 或停住。
6. 距離不足、機腹未朝牆、離牆太遠／太近、高度偏離及回頭時，能理解首次原因；重試不借用舊距離。
7. 碰到牆有實際碰撞，換課或自由飛行後沒有殘留隱形牆。
8. 桌面、窄畫面及全螢幕中，高度／XYZ、距牆、朝牆偏差及退出控制可讀；真人完成並重新整理後仍保留原條件的成績。

軟體與瀏覽器證據另見 [驗證紀錄](LEARNING_VALIDATION.md)，不代替 L20 人工操控驗收、實體控制器或飛手校準。
