# L18 刀旗 S 彎：試用與驗收

首次交付版本：**2026.11.02.1**；目前功能版本：**2026.11.09.1**。課程 ID：`slalom`，規則 **6**。使用者已於 2026-11-02 確認動作為「一路向前左右交替切彎」，不繞圈、不回頭，並指示開發。**使用者於 2026-11-11 明確回覆 L18 人工審核通過**。L01～L15、L17、L19 與自由鏡頭的既有核准保留；L16 倒刷鍋依使用者最新指示繼續暫緩人工驗證。

本課練習「地面自行起飛 → 沿旗列向前 → 第一旗左側、第二旗右側，依序交替至第六旗 → 繼續前飛離開旗列 → 回正恢復控制」。左右變化的是實際飛行路線，機身側傾與其餘軸配合完成切彎；不把左右晃動搖桿、原地偏航或固定側立角當成路線證據。

## 入口與第一輪練法

1. 更新本機、重新整理，確認頁首為 **2026.11.09.1**。若使用預覽模式，先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)。不必清除舊成績。
2. 在「選擇課程」選 **L18 刀旗 S 彎**，先觀看 **L18 刀旗 S 彎示範**。示範預設半速，應有自己的十步與逐旗章節；末幀為 **10／10**。
3. 辨認六面直立實體刀旗、旗號與當前通過側提示。先用 Chase 或暫停後的 Free / debug 看清楚一條持續向前的路線；指引線提供建議軌跡，不要求貼線。
4. 按「結束示範／回到練習」離開播放，選「引導練習（不限時）」並按「開始課程」。倒數後保持低油門，自行按 **Arm** 明確解鎖，再由地面起飛至約 **4 m**。
5. 依序從第一旗左側、第二旗右側、第三旗左側、第四旗右側、第五旗左側、第六旗右側通過。提早對準下一旗，讓實際航線左右交替，同時控制高度。
6. 第六旗通過後繼續向前飛約 **8 m**，逐步拉平並減緩升降與旋轉，恢復空中控制；不必停住或降落。

「左／右」固定以起飛時面向的前方判讀，不隨相機或機頭轉動改名。相對起飛點 **負 Z 為前方、負 X 為左、正 X 為右**。示範與練習的高度／XYZ 都顯示當時飛機位置，不能只看鏡頭畫面的左右。

## 旗列與通過空間

| 項目 | 初版設定 |
| --- | --- |
| 刀旗數量 | 六面，沿起飛時的前方排成一列。 |
| 與起飛點距離 | 16／28／40／52／64／76 m，旗距 12 m。 |
| 旗體 | 高 8 m、寬 0.6 m、厚 0.24 m；旗面與碰撞共用同一份幾何。 |
| 指定通過側 | 左／右／左／右／左／右，必須依序前向通過。 |
| 建議航線 | 離地約 4 m，經過各旗時左右偏移約 4 m。 |
| 過旗容許範圍 | 旗心指定側的水平偏移 1～8 m，離地 1～7 m。 |
| 旗列出口 | 第六旗後方再向前 8 m；不要求回原點。 |

這些是已獲使用者功能驗收的初版參數；更廣泛的新手／飛手校準仍另行追蹤。先用較寬的旗距理解換邊，後續若加入較短旗距，應另列難度與成績條件。

旗體是實心障礙，不是必須穿入的門框；從標示的那一側掠過，保留整架飛機及槳的空間。物理採保守全機包絡跨步掃掠，近旗時可能比可見機體邊緣更早碰撞。判定不能擴大到旗體內，亦不允許從旗頂上方飛越或離旗列很遠繞過。

## 十步與判定

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 在起飛區實際接地，明確解鎖。 |
| 2 自行起飛 | 自行離地，建立過旗高度。 |
| 3 第一旗左側 | 實際航跡向前穿過第一旗平面，位於左側容許空間。 |
| 4 第二旗右側 | 繼續前進，實際換到右側通過第二旗。 |
| 5 第三旗左側 | 再換向左側，依序通過第三旗。 |
| 6 第四旗右側 | 向右切彎，依序通過第四旗。 |
| 7 第五旗左側 | 向左切彎，依序通過第五旗。 |
| 8 第六旗右側 | 向右切彎，完成六旗。 |
| 9 向前飛離旗列 | 第六旗後繼續前飛至少 8 m。 |
| 10 恢復正飛與控制 | 空中回正、減緩升降與旋轉，確認 0.2 秒。 |

判定使用連續飛行線段與旗平面的真實交點，並依旗號檢查指定側及高度。左右交替的位移本身建立 S 彎，不要求傾斜到固定 90°、翻轉一圈、特定桿量、最低過旗速度或停留。原地左右搖晃、同一側直飛、回到同一組旗繞圈、倒著通過或瞬間改位置都不能完成。

恢復階段容許傾角 50° 內、機身角速度 180°/s 內、升降速度 ±6 m/s、水平速度 25 m/s 內，連續確認 0.2 秒；可以保持向前飛行，不需要懸停。引導練習不限時，能力挑戰 300 秒。課程不自動回平、定高、吸附路徑或代打搖桿。

## 看儀表與中斷原因

畫面保留高度與 XYZ，另顯示十步階段、已過旗數 **0／6～6／6**、下一旗及應通過的左／右側、與下一旗的前向距離、指定側偏移及實際前進速度。指定側偏移為正代表位於該旗要求的一側；仍須符合畫面明示的通過範圍。

一般偏離會保留**第一個中斷原因與當時量測**，不以稍後已修正的位置蓋掉錯因。

| 狀況 | 下一次修正 |
| --- | --- |
| 從錯側通過 | 查看中斷時旗號、指定側與偏移，提早對準下一段。 |
| 高度不符或從旗頂越過 | 調整至約 4 m；過旗離地範圍為 1～7 m。 |
| 離旗太遠繞過 | 過旗時回到指定側 1～8 m 空間，不必貼近旗體。 |
| 漏旗或跳過順序 | 回到第一旗前重新建立完整路線，依序通過六旗。 |
| 向後偏離已達進度超過 3 m | 本課要求一路前進；重新安排進場，不用繞回已過旗。 |
| 碰旗、墜毀或上鎖 | 按「再練一次」或重設課程，從地面明確解鎖後再試。 |

未墜毀的局部路線中斷，可回到第一旗前方重新進場；重新準備位置需至少在第一旗前 3 m，也就是尚未向前越過起飛點前方約 13 m 的位置。舊勾選只是本次教學里程碑，完成仍須來自新一段完整六旗、前飛改出與恢復，不能把中斷前後路線拼成通關。請先看中斷原因，不要在旗列中間直接接著刷剩餘旗。

## 示範、回放與紀錄

示範在獨立模擬中，以正常 RC、相同飛控及物理錄製；僅在開始時重設到實際地面，之後不覆寫飛行中位置、姿態或速度，並使用同一組旗體碰撞。真人仍需自行控制，示範不是輔助操控。

示範進度依同課 evaluator 觀察到的樣本建立。十步章節、字幕、搖桿、飛機與數值共用播放時鐘；按章節會暫停在該步開頭，可按 **Play** 繼續。倒退會恢復當時的旗數、當前目標及數值，不能保留後來才完成的步驟。觀看、暫停、重播、換鏡頭及退出示範，都不增加真人練習次數或成績。

真人結果使用新 `slalom` ID／規則 6，練習／挑戰、輸入來源、預設及調參脈絡分開保存；原有課程 ID、規則與原始紀錄保留。L16 暫緩驗證不會鎖住 L18，L17 或 L19 的完成標記也不能直接完成 L18。

## 人工核對清單

1. 頁首版本為 **2026.11.09.1**；選課及按鈕能找到 **L18 刀旗 S 彎**與其示範，原本課程及成績保留。
2. 示範從真實地面起飛，六旗依序左／右／左／右／左／右，持續向前而非繞圈；最後前飛離開、回正，結尾為 **10／10、6／6 旗**。
3. 每一旗有可辨識旗號、實體參照與通過側提示；FPV、Chase 及 Free / debug 都能看清楚路線。
4. 章節、半速、暫停及倒退時，旗數、飛機、搖桿、字幕與儀表一致；退出恢復真人練習，觀看不新增成績。
5. 自行由地面起飛，完成一次向前的六旗交替路線與改出；不需側立 90°、精準速度、停住或降落。
6. 錯側、漏旗、高飛越旗、遠離旗列及明顯回頭時，能辨認首次原因與當時數值；重試不借用舊旗數通關。
7. 碰到旗體有實際碰撞；退課或切到其他課程後，沒有本課留下的隱形旗體。
8. 桌面、短畫面及手機的高度／XYZ、旗數、下一側與播放提示可讀；完成真人練習並重新整理後，紀錄仍在原條件下。
