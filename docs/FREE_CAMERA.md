# 自由鏡頭：操作與核對

版本：**2026.10.27.2**。在 LIVE SIM、教學示範或飛行回放中，選擇 **Free / debug** 後可旋轉、移動及拉近／拉遠視角，不需要開啟 Developer HUD。FPV 仍是機上視角，Chase 仍是跟隨視角。

畫面下方提供「前移鏡頭 1 m／後移鏡頭 1 m／左移鏡頭 1 m／右移鏡頭 1 m」，與「升高鏡頭 1 m／降低鏡頭 1 m」一起操作。每次將鏡頭及觀察點移動 1 公尺，保持觀看角度及距離。前後左右依當前鏡頭朝向在水平面移動，即使鏡頭俯看也不會順便降低高度；上下則沿垂直方向移動。按鈕不要求先點 3D 畫面，點選後可連續按 Enter 操作。高度／XYZ 儀表仍顯示飛機位置。

## 滑鼠與鍵盤

先選 **Free / debug**。滑鼠可直接操作畫面；鍵盤操作前，先點一下 3D 畫面，或用 Tab 將焦點移到畫面。

| 操作 | 效果 |
| --- | --- |
| 左鍵拖曳 | 繞觀察點旋轉。 |
| 右鍵拖曳，或 Shift＋左鍵拖曳 | 平移視角與觀察點。 |
| 滑鼠滾輪 | 拉近／拉遠。 |
| 「前移鏡頭 1 m」／「後移鏡頭 1 m」 | 依鏡頭朝向在水平面前進／後退 1 公尺。 |
| 「左移鏡頭 1 m」／「右移鏡頭 1 m」 | 依鏡頭朝向在水平面左移／右移 1 公尺。 |
| 「升高鏡頭 1 m」／「降低鏡頭 1 m」 | 每次直接升高／降低鏡頭與觀察點 1 公尺。 |
| 方向鍵 | 依目前視角在水平面前進、後退、左移、右移。 |
| Page Up／Page Down | 升高／降低鏡頭；同時按住 Shift 也有效。 |
| Shift＋方向鍵 | 旋轉視角。 |
| ＋／－ | 拉近／拉遠。 |
| Home，或「定位飛機」 | 重新對準目前畫面中的飛機。 |

第一次切到自由鏡頭會對準當時的飛機位置；在示範／回放中對準的是當時的回放機體。之後切回 FPV／Chase 再進入自由鏡頭，會保留已移動的視角。想找回飛機時，使用「定位飛機」，不必重設飛行或重播影片。

## 與飛行及回放的關係

自由鏡頭只改變觀看位置與方向，不移動飛機、不代替搖桿、不解鎖／上鎖，也不改課程成績。移動鏡頭不會讓暫停中的示範繼續播放，也不改變時間軸或示範步驟。

LIVE SIM 仍持續依原本的飛行輸入與物理運作；切換自由鏡頭不會暫停模擬。若想從不同方向看同一個靜止動作，可以先暫停示範／回放，再移動鏡頭。

鏡頭快捷鍵只在 **Free / debug 且 3D 畫面有焦點** 時生效。切換鏡頭、焦點離開畫面、視窗失焦或頁面隱藏後，按住的鏡頭按鍵會釋放，避免返回時繼續移動。

鍵盤飛行使用的 W／S、A／D、Q／E、R／F 與 X 維持原本用途；自由鏡頭不將這些鍵改成鏡頭快捷鍵。使用「鍵盤體驗」時，這些仍是飛行／重設按鍵。鏡頭操作使用上表的另一組鍵。

## 人工核對清單

1. 在 LIVE SIM 選 Free / debug，依序操作前後左右及升降六個按鈕，確認前後左右保持鏡頭高度、升降保持水平位置，觀看角度不變。旋轉鏡頭後再按前移，應沿新的水平方向移動；也可連續按 Enter。飛機高度／XYZ 不受影響。再核對既有滑鼠及畫面焦點內鍵盤操作。
2. 將鏡頭移到別處，按「定位飛機」，確認回到目前機體；切換 FPV／Chase 後返回自由鏡頭，確認自訂視角保留。
3. 暫停任一示範，再操作自由鏡頭；確認時間、姿態、搖桿和示範進度維持暫停狀態，真人成績不增加。
4. 按住鏡頭鍵後移開焦點或切回 FPV，確認沒有持續漂移。操作表單、選課或文字欄位時，鏡頭快捷鍵不應搶走焦點。
