# L19 重力門：試用與驗收

本輪版本：**2026.10.30.1**。課程 ID：`gravity-gate`，規則 **6**。使用者已確認基礎動作流程並明確要求開發本課；**L19 人工操控驗收待回覆**。L01～L15、L17 與自由鏡頭的核准保留；L16 倒刷鍋已開發，使用者因難度較高暫緩人工驗證，不影響選擇本課，也不記為 L16 通過。

本課練習「帶速進場 → 向上拋射 → 收油調姿 → 從頂部向下進入框內 → 從指定側面飛出 → 恢復正飛與控制」。初版先完成一次清楚的進出流程，不要求緊貼門框、固定翻轉圈數、精準定點或完整八字串接。

## 入口與練法

1. 更新本機並確認頁首版本為 **2026.10.30.1**。使用預覽模式時先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)；不用清除舊成績。
2. 選擇 **L19 重力門**，先觀看 **L19 重力門示範**。示範預設半速，有自己的八步進度與章節；觀看、暫停、倒退及退出不增加真人練習次數或成績。
3. 辨認起飛點前方約 **40 m** 的立體門框：**頂部為入口，遠側側面為出口**。先切換 Chase 或暫停後使用 Free / debug 看清楚門框上下及前後的關係。
4. 開始課程、倒數後保持低油門，明確解鎖，再從實際地面自行起飛至建議約 **14 m**；起飛步驟至少需要離地 **4 m**。在門前留出距離，建立可控前速。
5. 配合俯仰及油門向上拋射，讓實際路線升到離地 **24 m** 的頂部開口上方，建議上拋至約 **28～30 m**，保留高度與調姿空間。
6. 越頂時降低油門，配合橫滾、俯仰調整機體與下落路線。看頂部入口的左右、前後偏差，讓飛機由上往下穿過頂部開口；不能只在頂框上方掠過。
7. 進入框內後，對準標示的遠側出口，從側面向外飛出。不要朝底框直落，也不要在剛進框時急著大幅補油。
8. 離框後拉平、減緩下沉與旋轉，恢復空中控制即可完成；不用降落、回原點或停在指定位置。

上拋靠的是已建立的實際速度與向上運動；收油是為下落調姿保留空間，並不會把飛機吸向門框。接近倒置時一般推力會朝地面，過早大幅補油可能加速下沉。先看飛機姿態、實際下降速度及出口位置，再逐步補油改出；本課不提供自動回平、吸附路徑或代打搖桿。

## 門框與儀表

| 場景項目 | 本版設定 |
| --- | --- |
| 淨開口 | 左右寬 14 m、前後深 14 m、內部高 14 m。 |
| 框底／框頂 | 離地 10 m／24 m，隨設定地面高度平移。 |
| 位置 | 中心位於起飛點前方 40 m，隨起飛點 X／Z 平移。 |
| 頂部入口 | 框頂的水平開口，必須由上向下穿過。 |
| 指定側面出口 | 遠側（−Z）的垂直開口，必須在頂部入框後向外穿過。 |
| 實體結構 | 12 根框梁，梁厚 0.35 m；四柱延伸至地面，幫助辨認高度。 |

門框、可通行開口、穿越判定與碰撞使用同一份幾何。頂部及側面沒有隱藏實心面；框梁有真實碰撞。判定會保留整架飛機的保守包絡空間，槳邊與門角也可能碰撞，所以應從寬敞開口中央附近通過。路徑、入口、出口與高度標記只作引導，不會改變飛機狀態。

原有高度與相對起飛點 XYZ 保留；負 Z 表示向起飛時的前方移動。本課另提供當前階段、頂部入口的相對位置及側出口距離，讓漏門時能分辨自己偏左／偏右、飛得太前／太後，或尚未下降穿入。即時數值屬於目前飛行；首次中斷的測量值會另行保留，不以後來的位置覆蓋當時原因。

Chase 方便查看實際航跡，Free / debug 可旋轉、平移、縮放及以六向按鈕移動。暫停示範後操作相機不改播放時間、飛機或成績，詳見 [自由鏡頭操作](FREE_CAMERA.md)。

## 八步與連續動作

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 在起飛區實際接地，明確解鎖後才評分。 |
| 2 自行起飛 | 自行離開地面，保留後續上拋與改出的空間。 |
| 3 建立前進速度 | 先觀察真實前速，不以搖桿前推或原地轉頭代替位移。 |
| 4 向上拋射 | 同一段進場真的開始上升，向頂部入口取得高度。 |
| 5 收油並調整姿態 | 在上拋後降低油門並實際調姿，為下落及改出準備。 |
| 6 由頂部向下入框 | 實際航跡由上往下穿越頂部開口，機體包絡避開實心梁。 |
| 7 從指定側面飛出 | 入框後在內部高度範圍，向外穿越遠側出口。 |
| 8 恢復正飛與控制 | 在空中回正、減緩升降與旋轉，完成短暫穩定確認。 |

| 條件 | 初版寬鬆範圍 |
| --- | --- |
| 建議／最低起飛高度 | 約 14 m／至少 4 m；上拋建議約 28～30 m。 |
| 練習空間 | 起飛點水平半徑 150 m；動作中低於 2 m 或接地會中斷本次局部路線。 |
| 前飛準備 | 在門框近側，向前（−Z）速度至少 1.5 m/s、機頭與速度方向差不超過 60°、升降速度在 ±1.5 m/s 內，連續約 0.1 秒。 |
| 上拋證據 | 從這次前飛準備的位置實際升高至少 1 m、上升速度至少 1.2 m/s，且起拋時仍有向前（−Z）速度至少 0.5 m/s。真正入框時仍須到達 24 m 頂部以上。 |
| 收油 | 上拋後觀察油門降低；判定上限為 `max(0.12, min(0.60, 本次峰值油門 × 0.85))`。峰值以本次動作計算，不借用前次高油門。 |
| 調姿 | 機身上方方向相較本次前飛準備實際改變至少 8°，並觀察升速較峰值減少至少 0.5 m/s；不限定橫滾或俯仰的固定圈數。 |
| 進出 | 同一段路線由頂部向下穿入，再從遠側向外穿出，均需落在真實開口內；沒有擴大穿牆容差。 |
| 恢復控制 | 離框後傾角不超過 45°、機身角速度不超過 180°/s、升降速度在 ±6 m/s 內、水平速度不超過 25 m/s，連續確認 0.2 秒。 |
| 時間 | 引導練習不限時；能力挑戰 300 秒。 |

前速、上拋、收油調姿、頂部進入、側面離開與恢復必須來自同一次有效連續動作。建立前飛後、尚未上拋時，如果向前速度連續 0.75 秒不足 0.5 m/s，會中斷局部動作並提示先重新建立前速；已上拋後接近頂點的自然減速不受這條限制。先前的勾選只是教學里程碑；局部中斷後仍須重新建立需要的動作證據，不能利用舊勾選直接通關。引導練習不限時，門檻以完成核心動作與可控改出為主，不強迫精準線路、懸停或降落。

從側面直接穿過、由底部向上進入、掠過框頂、從其他側面離開、尚未進框就飛走、進出次序顛倒，均不能代替本課的指定流程。墜毀、上鎖、重設或時間／位置／姿態資料不連續會停止本次練習；不能藉瞬移、覆寫姿態或拼接不同次飛行完成。

## 錯誤後怎麼重試

先看畫面保留的**第一個中斷原因與當時量測**，再看目前的入口與出口指引。仍能控制且未墜毀時，依提示離開門框、回到門前重新進場；一般漏門不需要清除所有歷史紀錄。框梁碰撞造成墜毀時，先 Disarm，再明確重設課程，從地面重新開始。

| 看見的情況 | 下一次修正 |
| --- | --- |
| 未從頂部進入 | 先升到框頂上方，再確認下落路線確實穿入頂部開口。側面進框不算。 |
| 頂部入口左右或前後偏離 | 在越頂前提早修正水平位置，少量調姿，避免下降時才大幅追門。 |
| 進框後落到太低或從其他面出去 | 進入後提早辨認遠側出口，調整姿態與油門，保留穿過側開口的高度。 |
| 碰到門梁 | 從寬敞開口中央附近通過；飛機有尺寸，不能把槳尖當作可穿過實心框。 |
| 已出框但尚未完成 | 先減少殘餘旋轉與下沉，恢復正飛；通過出口不等於已恢復控制。 |

## 示範、成績與人工核對

示範從地面透過正常搖桿輸入、同一套飛控與物理實際錄製，使用相同門框碰撞；不在飛行途中覆寫位置或姿態，也不接管真人控制。八步與章節由觀察到的實際樣本及本課判定建立，不以字幕或播放時間直接宣告完成。

本版新手示範約 **15.42 秒**、保留 **926 個樣本**，約 **14.60 秒**完成全部八步；半速觀看約 **31 秒**。八步觀察時間約為 **0、2.15、6.33、10.37、11.10、13.13、14.40、14.60 秒**。實際最高約 **27.47 m**；頂部入框時為 **24 m**，側面出框時約 **19.11 m**。這些是同物理錄影的實測值，不是精準高度要求或真人操控證據。

示範結尾應為 **8／8**。暫停、半速、章節與向後拖曳時，機體、搖桿、字幕、儀表與勾選保持同一時間；倒退會恢復當時進度。退出後回到原本學習畫面，不把示範進度或結果寫成真人成績。

本課使用獨立 `gravity-gate` ID／規則 **6**。練習、挑戰、輸入來源、預設及調參條件仍依既有 context 分開保存；L16 未驗收不會鎖住 L19，其他課程的次數、最近／最佳、原始偏好與 L00 觀念紀錄保留。
