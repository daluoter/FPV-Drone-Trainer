# L19 重力門：試用與驗收

本輪版本：**2026.10.30.2**。課程 ID：`gravity-gate`，規則 **7**。使用者指出上一版路線不符，並明確確認為「上拋後仍由水平頂口向下落入，降到低層後折返，從來向那側飛出」；本版依此修正進場、下降及返回路線，並縮小、降低為兩層門框。**L19 人工操控驗收仍待回覆**。L01～L15、L17 與自由鏡頭的核准保留；L16 因難度暫緩人工驗證，不影響選擇本課。

本課練習「地面起飛 → 側邊帶速進場 → 向上拋射 → 收油調姿 → 水平頂口向下入框 → 框內降到低層 → 折返、從來向同側的低層出口飛出 → 恢復正飛與控制」。先完成一次清楚的進出流程，不要求精準半圓、固定翻轉圈數、貼框、定點或完整八字串接。

## 入口與練法

1. 更新本機並確認頁首版本為 **2026.10.30.2**。使用預覽模式時先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)；不用清除舊成績。
2. 選擇 **L19 重力門**，先觀看 **L19 重力門示範**。示範預設半速，有自己的八步進度與章節；觀看、暫停、倒退及退出不增加真人練習次數或成績。
3. 辨認起飛點前方約 **28 m** 的兩層門框、金色水平頂口，以及來向那側的青色低層返回出口。先用 Chase 或暫停後的 Free / debug 查看上層、低層與側邊進場箭頭。
4. 開始課程，倒數後保持低油門，明確解鎖，再從地面自行起飛至建議約 **8 m**。飛到門框側邊的進場參照，沿箭頭建立朝框內的實際速度。
5. 帶著側向進場速度，配合俯仰與油門向上拋射，取得 **14 m** 頂口上方的空間，建議上拋至約 **17～18 m**。
6. 提早降低上拋時的油門並調姿，對準水平頂口，讓真實下落路線由上往下穿入。入框後繼續在框內下降，穿過開放中環，進入低層。
7. 到達低層後，先減少原進場速度，確認接近停住或仍朝框內的狀態，再朝來向那側的青色出口建立返回位移。畫面會分別顯示頂入、到達低層與折返準備；只轉動機頭不會讓移動方向立即反轉。
8. 從低層出口飛離後，拉平並減緩升降與旋轉，恢復空中控制即可完成；不用降落、回原點或停在指定位置。

上拋靠的是已建立的速度與向上運動；收油及調姿用來安排下落與改出空間。入框後要持續觀察下降高度、實際移動方向和青色出口的位置，再逐步補油與反向修正。本課不提供自動定高、回平、吸附路徑或代打搖桿。

## 門框、方向與儀表

| 場景項目 | 本版設定 |
| --- | --- |
| 兩層門框 | 寬 8 m、深 8 m，框底至頂口內高 10 m。 |
| 底／中／頂 | 離地約 4／9／14 m，隨設定地面高度平移。 |
| 位置 | 中心位於起飛點前方 28 m，隨起飛點 X／Z 平移。 |
| 側邊進場 | 先到框中心右側約 14 m、高約 8 m 的參照，再朝框中心前進。依起飛點座標，進場沿 −X。 |
| 頂部入口 | 仍是金色水平頂口，必須由上向下落入。 |
| 低層返回出口 | 位於進場來向的同一側（＋X），淨高度約 4～8.86 m；到達低層後沿＋X返回飛出。 |
| 實體結構 | 16 根框梁，梁厚 0.28 m；四柱延伸至地面，中環只在外周，不是隱藏地板。 |

門框、可通行開口、穿越判定與碰撞使用同一份幾何。水平頂口、中環中央與低層出口可通行，框梁有真實碰撞。物理碰撞保留整架飛機的保守包絡空間，槳邊與門角也可能碰撞；穿越容差不會擴大到實心框梁。路徑、標記與箭頭只作引導，不會改變飛機狀態。

原有高度與相對起飛點 XYZ 保留；負 Z 仍表示起飛時的前方。L19 的進場與返回沿框側的 X 方向，攝影機轉動不改變箭頭與出口。另可查看入口偏差、高度差、低層是否已到達，以及實際返回速度與出口距離。即時數值屬於目前飛行，第一次中斷的當時量測會另外保留。

Chase 方便觀察側邊上拋、框內下降與折返，Free / debug 可旋轉、平移、縮放及以六向按鈕移動。暫停示範後操作相機不改播放時間、飛機或成績，詳見 [自由鏡頭操作](FREE_CAMERA.md)。

## 八步與連續動作

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 在起飛區實際接地，明確解鎖後才評分。 |
| 2 自行起飛 | 自行離地，前往側邊進場區並保留上拋空間。 |
| 3 建立進場速度 | 觀察沿側邊箭頭朝框內的真實速度，不以搖桿前推或原地轉頭代替位移。 |
| 4 向上拋射 | 同一段側邊進場真的向上拉升，取得水平頂口上方的高度。 |
| 5 收油並調整姿態 | 上拋後降低油門並實際調姿，為下落及返回準備。 |
| 6 由頂口向下入框 | 真實航跡由上往下穿過金色水平開口。 |
| 7 降低層、折返並側出 | 入框後在框內下降到低層，建立實際反向位移，再從來向同側的低層出口飛出。 |
| 8 恢復正飛與控制 | 在空中回正、減緩升降與旋轉，完成短暫穩定確認。 |

第七步會細分顯示「尚待下降到低層」與「尚待折返返回」。反向指的是實際速度及位移改變；只做偏航、只改字幕，或從上層直接飛出，都不能代替低層返回。

| 條件 | 本版寬鬆範圍 |
| --- | --- |
| 建議／最低起飛高度 | 約 8 m／至少 4 m；上拋建議約 17～18 m。 |
| 側邊進場準備 | 在門框右側進場走廊，朝框內（−X）速度至少 1.5 m/s，機頭與移動方向差不超過 60°，升降速度在 ±1.5 m/s 內，連續約 0.1 秒。 |
| 上拋證據 | 本次進場後實際升高至少 1 m、上升速度至少 1.2 m/s，起拋時仍保留至少 0.5 m/s 的朝框內速度。 |
| 收油與調姿 | 油門降至 `max(0.12, min(0.60, 本次峰值油門 × 0.85))` 以下，機身上方方向實際改變至少 8°，且升速較本次峰值減少至少 0.5 m/s。 |
| 到達低層 | 頂口入框後，在框內實際向下降過約 8.86 m 的低層上界；中環外周有實體梁。 |
| 低層折返準備 | 在框內低層量到尚未開始朝來向返回的狀態：＋X 速度不超過 0.2 m/s，可仍朝框內或近乎停住，再建立回程。 |
| 實際返回 | 同一段連續低層飛行，＋X 速度至少 0.5 m/s，並從本段最內側位置產生至少 0.3 m 淨返回位移；來回晃動不累加距離。 |
| 指定出口 | 從來向同側的＋X面，於離地約 4～8.86 m 淨開口內向外飛出；飛機包絡仍須避開框梁。 |
| 恢復控制 | 離框後傾角不超過 45°、機身角速度不超過 180°/s、升降速度在 ±6 m/s 內、水平速度不超過 25 m/s，連續確認 0.2 秒。 |
| 空間與時間 | 起飛點水平半徑 150 m；低於 2 m 或接地會中斷本段。引導練習不限時，能力挑戰 300 秒。 |

若尚未完成返回就升回上層，會清除尚未完成的折返準備與回程位移；回到低層後重新建立，不能借用上層的移動完成。上拋前若朝框內速度連續 0.75 秒不足 0.5 m/s，會要求重建側邊進場；已上拋後的自然減速不受這條限制。

前速、上拋、收油調姿、頂口進入、框內下降、低層返回與恢復必須來自同一次有效連續動作。先前勾選只是教學里程碑；局部中斷後仍要重新建立本次路線的證據，不能借用舊頂入或舊出口。引導練習不限時，門檻以完成核心動作和可控改出為主，不強迫精準線路、懸停或降落。

從垂直側面直接入框、由底部向上穿入、只掠過頂口、尚未降低層就從上層側出、從遠端向前直出，或先離框再繞回低層，均不能完成本課。墜毀、上鎖、重設或不連續的時間／位置／姿態資料會停止本次練習。

## 錯誤後怎麼重試

先看保留的**第一個中斷原因與當時量測**，再看目前指引。仍可控制且未墜毀時，依提示飛離門框、回到側邊進場參照重新建立整段路線；碰框墜毀後，明確重設課程並從地面重新開始。

| 看見的情況 | 下一次修正 |
| --- | --- |
| 沒有側邊進場速度 | 先到進場參照，沿箭頭建立朝框內的速度，再上拋。 |
| 入口左右或前後偏離 | 越頂前提早修正水平位置，讓下落路線穿過金色水平頂口。 |
| 已入框但尚未到低層 | 留在框內下降，觀察中環與低層返回出口高度。 |
| 已到低層但尚未折返 | 先減少原進場速度，讓低層折返準備被觀察到，再朝來向建立返回速度及淨位移；轉頭本身不會立即反轉速度。 |
| 從上層或其他面出去 | 下一次先在框內下降到低層，再對準來向那側的青色出口。 |
| 碰到框梁 | 為整架飛機及槳保留距離，尤其留意中環、低層頂緣與立柱。 |
| 已出框但尚未完成 | 主動回正，減少殘餘下降與旋轉，完成空中恢復確認。 |

## 示範、成績與人工核對

示範從地面透過正常搖桿輸入、同一套飛控與物理實際錄製，使用相同門框碰撞；不在飛行途中覆寫位置或姿態，也不接管真人控制。八步、低層下降和返回證據由觀察到的實際樣本建立，不以字幕或播放時間宣告完成。

本版實際物理示範約 **21.30 秒**、保留 **1279 個樣本**且未丟棄，約 **20.48 秒**完成八步；半速觀看約 **42.6 秒**。八步觀察時間約為 **0、2.15、13.57、14.92、15.47、17.23、20.28、20.48 秒**，最高離地約 **16.98 m**。約 **17.23 秒／14 m** 由頂口落入，約 **18.30 秒／8.86 m** 下降到低層時仍向框內移動；其後才建立朝來向的正向返速。約 **20.28 秒／6.33 m** 從同側低層出口飛出，末幀約 **6.43 m**，機頭與實際移動均朝來向。這些是錄影實測，並非要求使用者貼著精準時間、半圓或高度飛行。

示範結尾應為 **8／8**。暫停、半速、章節與向後拖曳時，機體、搖桿、字幕、儀表與勾選保持同一時間；倒退會恢復當時的頂入、低層與返回狀態。退出後回到原本學習畫面，不把示範進度或結果寫成真人成績。本輪實測時間、樣本與檢查證據另記於 [驗證紀錄](LEARNING_VALIDATION.md)，不沿用上一版向前側出的錄影數據。

本課沿用 `gravity-gate` ID，但修正後使用規則 **7**。舊規則 **6** 的原始成績及完成紀錄保留在原條件下，不直接轉算新路線通關。其他課程維持原規則，練習／挑戰、輸入來源、預設及調參條件仍分開保存；L16 未驗收不會鎖住 L19。

人工核對：

1. 頁首為 **2026.10.30.2**，兩層門框已縮小、降低；側邊進場與低層返回箭頭清楚，L16、L17 及舊成績保留。
2. 觀看示範，能辨認側邊上拋、水平頂口落入、框內降低層、折返往來向飛出與回正；結尾八步全部完成。
3. 切換頂入、低層返回及恢復章節，確認機體路線、速度與進度一致；倒退不保留未發生的低層或返回證據。
4. 自行完成一次「頂口下入 → 框內降低層 → 來向同側返回 → 恢復控制」，不用固定半圓、翻滿一圈、完整八字、定點或降落。
5. 上層直接側出、向遠端直出、漏過頂口或碰框時，提示能說明原因與當時量測，局部重試不能借用舊勾選通關。
6. 門框有碰撞，頂口及中環中央可通行；退課、自由飛行與其他課程不保留本課看不見的碰撞場。
7. 高度／XYZ、低層與返回狀態在桌面及窄畫面可讀；示範不增加真人成績，真人結果重新整理後仍在，舊規則 6 不直接完成新規則 7。
