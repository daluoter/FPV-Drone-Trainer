# L19 重力門：試用與驗收

本輪版本：**2026.11.01.1**。課程 ID：`gravity-gate`，規則 **7**。依使用者最新更正，上拋的來向與方式不限，只要能由**水平頂口向下落入**；入框後仍須在框內降到低層、實際折返，從**本次來向同側的低層出口**飛出。示範改為正面上拋、正面底層返回。**L19 人工操控驗收仍待回覆**；L01～L15、L17 與自由鏡頭的核准保留，L16 因難度暫緩人工驗證。

本課練習「地面起飛 → 取得頂口上方空間 → 水平頂口向下入框 → 框內降到低層 → 折返、從來向同側飛出 → 恢復控制」。先完成一次清楚的進出流程，不要求精準半圓、固定翻轉圈數、貼框、定點或完整八字。

## 入口與練法

1. 更新本機並確認頁首版本為 **2026.11.01.1**。使用預覽模式時先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)；不用清除舊成績。
2. 選擇 **L19 重力門**，先觀看 **L19 重力門示範**。示範預設半速，有自己的八步進度與章節；觀看、暫停、倒退及退出不增加真人練習次數或成績。
3. 辨認起飛點前方約 **28 m** 的兩層門框、金色水平頂口與青色低層出口。先用 Chase 或暫停後的 Free / debug 查看框內下降與返回路線。
4. 開始課程，倒數後保持低油門，明確解鎖，再從地面自行起飛。建議先到約 **8 m**，由正面接近，向上拋到約 **17～18 m**，取得 **14 m** 頂口上方空間；也可由左、右或後方進場。
5. 依自己的操作對準頂口，讓真實下落路線由上往下穿入。系統不要求特定收油量、姿態改變角度、機頭角度或進場速度；有效頂入會補足前段引導里程碑。
6. 入框後留在框內下降，穿過開放中環，到達低層。青色出口依本次來向顯示，頂入後固定，不因轉動機頭或相機改變。
7. 到達低層後先減少原進場速度，讓接近停住或仍朝框內的狀態被觀察到，再朝來向那側建立實際返回速度及淨位移。只轉動機頭不會讓速度立即反轉。
8. 從同側低層出口飛離後，拉平並減緩升降與旋轉，恢復空中控制即可完成；不用降落、回原點或停在指定位置。

油門與姿態由使用者自行控制，課程不提供自動定高、回平、吸附路徑或代打搖桿。保留足夠上拋與改出空間，依高度、實際速度與出口方向逐步修正。

## 門框、方向與儀表

| 場景項目 | 本版設定 |
| --- | --- |
| 兩層門框 | 寬 8 m、深 8 m，框底至頂口內高 10 m。 |
| 底／中／頂 | 離地約 4／9／14 m，隨設定地面高度平移。 |
| 位置 | 中心位於起飛點前方 28 m，隨起飛點 X／Z 平移。 |
| 預設示範來向 | 正面是朝起飛點的這一面（框中心的＋Z側）；進場參照距框中心約 14 m、高約 8 m，沿 −Z 接近，低層沿＋Z返回。 |
| 其他來向 | 左、右、後方也可頂入；依進頂口前最後一次位於框外的方向辨識本次來向。角落採一致的方向選擇；沒有可辨識的框外來向時使用正面。 |
| 頂部入口 | 金色水平頂口，必須由上向下落入。 |
| 低層返回出口 | 本次來向同側，頂入後固定；淨高度約 4～8.86 m。 |
| 實體結構 | 16 根框梁，梁厚 0.28 m；四柱延伸至地面，中環只有外周梁。 |

門框、可通行開口、穿越判定與碰撞使用同一份幾何。水平頂口、中環中央與低層出口可通行，框梁有真實碰撞。物理碰撞保留整架飛機的保守包絡空間，槳邊與門角也可能碰撞；穿越容差不會擴大到實心框梁。路徑與箭頭只作引導。

高度與相對起飛點 XYZ 保留；負 Z 仍是起飛時的前方。另可查看本次來向、頂入、低層、折返及同側出框狀態，以及朝該出口的實際返回速度、淨位移和出口距離。向出口返回的速度為正，不能固定只看 X 或 Z。第一次中斷的當時量測會另外保留。

Chase 方便觀察正面上拋、框內下降與折返；Free / debug 可旋轉、平移、縮放及以六向按鈕移動。暫停示範後操作相機不改播放時間、飛機或成績，詳見 [自由鏡頭操作](FREE_CAMERA.md)。

## 八步與連續動作

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 在起飛區實際接地，明確解鎖後才評分。 |
| 2 自行起飛至進場高度 | 自行離地，取得頂口上方空間。 |
| 3 確認本次進場來向 | 從框外位置辨認本次返回面，不限制從哪一面上拋。 |
| 4 取得頂口上方高度 | 取得水平頂口上方的下落空間。 |
| 5 對準水平頂口 | 讓下落航線對準水平開口，不要求指定油門或姿態。 |
| 6 從頂部向下入框 | 真實航跡由上往下穿過金色水平開口；有效穿越會補足前段引導里程碑。 |
| 7 下降至低層並折返側出 | 在框內下降到低層，建立實際反向位移，再從來向同側的低層出口飛出。 |
| 8 恢復正飛與控制 | 在空中回正、減緩升降與旋轉，完成短暫穩定確認。 |

第三至第五步是路線引導；它們不會以某種上拋手法拒絕真正的頂口下入。第七步會細分「尚待下降到低層」「尚待折返準備」及「尚待返回位移」。反向指實際速度與位移，原地偏航不能代替。

| 條件 | 本版寬鬆範圍 |
| --- | --- |
| 建議／最低起飛高度 | 約 8 m／至少 4 m；上拋建議約 17～18 m。 |
| 頂口進入 | 從上向下穿過水平淨開口；上拋來向、油門、姿態、機頭角度與進場速度不另設門檻。 |
| 到達低層 | 頂口入框後，在框內實際向下降過約 8.86 m 的低層上界。 |
| 低層折返準備 | 在框內低層量到朝返回面的速度不超過 0.2 m/s，可仍朝框內或近乎停住，再建立回程。 |
| 實際返回 | 同一段連續低層飛行，朝本次來向的速度至少 0.5 m/s，並從本段最內側位置產生至少 0.3 m 淨返回位移；來回晃動不累加距離。 |
| 同側出口 | 從頂入時固定的來向面，於離地約 4～8.86 m 淨開口內向外飛出；飛機包絡仍須避開框梁。 |
| 恢復控制 | 離框後傾角不超過 45°、機身角速度不超過 180°/s、升降速度在 ±6 m/s 內、水平速度不超過 25 m/s，連續確認 0.2 秒。 |
| 空間與時間 | 起飛點水平半徑 150 m；低於 2 m 或接地會中斷本段。引導練習不限時，能力挑戰 300 秒。 |

若尚未完成返回就升回上層，會清除尚未完成的折返準備與回程位移；回到低層後重新建立，不能借用上層移動。頂口進入、框內下降、低層返回與恢復須來自同一次有效連續動作。先前勾選只是里程碑；局部中斷後須重新建立本次路線證據。

從垂直側面直接入框、由底部向上穿入、只掠過頂口、尚未降低層就從上層側出、從非來向的一面出框，或先離框再繞回低層，均不能完成本課。墜毀、上鎖、重設或不連續的時間／位置／姿態資料會停止本次練習。

## 錯誤後怎麼重試

先看保留的**第一個中斷原因與當時量測**，再看目前指引。仍可控制且未墜毀時，飛離門框重新安排頂口下入；不必回指定的一面建立速度。碰框墜毀後，明確重設課程並從地面重新開始。

| 看見的情況 | 下一次修正 |
| --- | --- |
| 入口左右或前後偏離 | 越頂前提早修正水平位置，讓下落路線穿過金色水平頂口。 |
| 已入框但尚未到低層 | 留在框內下降，觀察中環與低層返回出口高度。 |
| 已到低層但尚未折返 | 先減少原進場速度，再朝來向建立返回速度及淨位移；轉頭不會立即反轉速度。 |
| 從上層或其他面出去 | 下一次先在框內下降到低層，再對準本次來向的青色出口。 |
| 碰到框梁 | 為整架飛機及槳保留距離，尤其留意中環、低層頂緣與立柱。 |
| 已出框但尚未完成 | 主動回正，減少殘餘下降與旋轉，完成空中恢復確認。 |

## 示範、成績與人工核對

示範從地面透過正常搖桿輸入、同一套飛控與物理實際錄製，使用相同門框碰撞；不在飛行途中覆寫位置或姿態，也不接管真人控制。預設從正面上拋，由頂口下入、框內降低層，再從正面低層返回。八步與返回證據由實際樣本建立，不以字幕或播放時間宣告完成。本輪實測時間與檢查結果另記於 [驗證紀錄](LEARNING_VALIDATION.md)。

本版示範約 **17.05 秒**，半速觀看約 **34.1 秒**；約 **13.00 秒**頂口下入、**14.05 秒**到達低層、**16.03 秒**同側飛出，約 **16.23 秒**完成恢復。這些是示範實測，不是使用者必須遵守的時間。

示範結尾應為 **8／8**。暫停、半速、章節與向後拖曳時，機體、搖桿、字幕、儀表、來向及勾選保持同一時間；倒退會恢復當時狀態。退出後回到原本學習畫面，不把示範進度或結果寫成真人成績。

本課沿用 `gravity-gate` ID／規則 **7**，已有規則 7 成績及完成紀錄保留。舊規則 **6** 的原始紀錄仍保留在原條件下，不直接轉算新路線通關。其他課程維持原規則，練習／挑戰、輸入來源、預設及調參條件仍分開保存；L16 未驗收不會鎖住 L19。

人工核對：

1. 頁首為 **2026.11.01.1**，正面進場與低層返回箭頭清楚；L16、L17 及舊成績保留。
