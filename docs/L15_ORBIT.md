# L15 正刷鍋：試用與驗收

本輪版本：**2026.10.28.1**。課程 ID：`orbit`，地面教學使用規則 **6**。依使用者接續要求，本課須在目標清楚可見、機頭持續朝向目標的狀態下，真正側移完成 **至少五個完整圈**，之後才實際向塔外飛離並恢復控制。地面起飛、進場、五圈與改出共 **九步**；先前單圈初稿已由此要求取代。**使用者於 2026-10-28 明確回覆「L15 審核通過」，本五圈版本人工驗收通過**；五圈版的 1190 項完整測試、Lint、嚴格建置及 51 項正式產物瀏覽器檢查均已通過，見 [驗證紀錄](LEARNING_VALIDATION.md)。

本次 L15 核准對應 `2026.10.28.1`／`00a3c3d` 五圈交付脈絡；既有自由鏡頭及 L01～L14 核准保留。使用者未另提供本機版本、瀏覽器或設備細節，不擴張為共通硬體／飛手校準證據。

## 入口與練法

1. 更新本機網頁並確認頁首版本。預覽模式先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)；不用清除本機紀錄。
2. 選擇 **L15 正刷鍋**，先觀看 **L15 正刷鍋示範**。本課有自己的九步、圈數、章節及儀表，預設半速；觀看不增加真人次數或成績。
3. 開始課程、倒數後保持低油門，明確解鎖，再從地面自行起飛。建議先升至約 **10 m**；參考目標位於起飛點正前方約 **30 m**、離地 **10 m**。
4. 在約 **15 m 半徑**的寬鬆環繞區準備，先找到清楚可辨認的目標並把機頭朝向它。以少量橫滾建立側移，再配合偏航持續讓目標留在機頭前方，油門配合維持高度。
5. 任選左繞或右繞，維持同一方向真正繞行。第一圈至第五圈依實際航跡逐步勾選；每圈都是完整 **360°**，合計至少 **1800°**。觀察圈數到 **5／5** 後才離開，不能繞一圈就改出。
6. 五圈完成後，從當時的繞行半徑繼續向塔外飛離至少 **3 m**，向外速度至少 **0.5 m/s**，同時帶回接近水平並恢復可控飛行。只放慢繞行或停在原處不算離開；五圈後可轉向塔外，不必繼續把機頭朝塔，也不用降落或完全停住。

本課練「目標保持可見，機頭持續朝向目標，機體真正側移繞目標五圈」。原地轉機頭、機頭一直朝前的普通轉圈、直線擦過目標，或在同一小段反覆來回，都不能代替本次完整五圈。偏航本身不會讓飛機開始繞行，仍需協調實際移動與推力。

## 參考目標與畫面

場景顯示可辨認的目標塔、約 15 m 的參考圓周、入口及階段標記。練習時持續把目標留在視野中，觀察它與機頭的關係；標記幫助辨識位置，不要求貼圓線或精準固定半徑，也不新增碰撞物。

高度及相對起飛點的 XYZ 保留。正刷鍋儀表另顯示本輪淨環繞角、完整圈數（目標 **5／5**）、繞行半徑及機頭朝向目標的誤差。從 FPV 看目標與視野的關係；想看整體航跡，可切換 Chase，或暫停示範後使用 Free / debug 與六向按鈕，見 [自由鏡頭操作](FREE_CAMERA.md)。鏡頭移動不改飛機、播放時間或課程成績。

## 九步與寬鬆範圍

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 起飛區實際接地，保持低油門並明確解鎖。 |
| 2 自行起飛 | 最低起飛確認高度 4 m，建議約 10 m。 |
| 3 環繞進場 | 找到可見目標，在寬鬆半徑／高度內朝向目標並建立側移。 |
| 4 完成第一圈 | 同一連續動作淨環繞至少 360°。 |
| 5 完成第二圈 | 同一連續動作淨環繞至少 720°。 |
| 6 完成第三圈 | 同一連續動作淨環繞至少 1080°。 |
| 7 完成第四圈 | 同一連續動作淨環繞至少 1440°。 |
| 8 完成第五圈 | 同一連續動作淨環繞至少 1800°，圈數達 5／5。 |
| 9 飛離參考塔並恢復控制 | 五圈後實際向外增加至少 3 m 半徑，保持向外速度至少 0.5 m/s，帶回可控正飛並連續確認 0.2 秒。 |

| 條件 | 本版範圍 |
| --- | --- |
| 建議高度／半徑 | 約 10 m／15 m。 |
| 繞行高度 | 離地 4～20 m。 |
| 繞行半徑 | 距目標 6～30 m。 |
| 側向移動 | 切線方向至少 0.75 m/s，不接受原地偏航累積角度。 |
| 繞行時目標與朝向 | 持續觀察可見目標並讓機頭朝向它；朝向誤差不超過 80°，不用正好置中。五圈後離塔可轉向外側。 |
| 最少圈數 | 同方向連續五個完整 360° 圈，淨環繞至少 1800°。 |
| 練習空間 | 起飛點水平半徑 150 m。 |
| 實際離塔 | 五圈完成時固定半徑，之後向外增加至少 3 m，徑向向外速度至少 0.5 m/s；只減速或懸停不能代替。 |
| 恢復高度／姿態 | 離地至少 1.5 m，傾角不超過 35°，機身角速度不超過 140°/s。 |
| 恢復移動 | 水平速度不超過 15 m/s，升降速度 −4～+5 m/s，連續確認 0.2 秒。 |
| 時間 | 引導練習不限時，能力挑戰 300 秒。 |

里程碑顯示已觀察過的教學階段；完成判定另保留本次連續五圈的證據。一般偏離短暫容許修正，持續超出半徑、高度、朝向或側移範圍約 0.75 秒，或明顯反向超過 45°，會清除本輪角度、有效圈數及恢復證據。畫面保留首次中斷原因與當時數值；重新準備後需完成新的一組五圈，不能借用舊圈數或勾選直接通關。地面起飛與已觀察階段不會假裝變成新的有效圈數。

墜毀、解除解鎖、重設、時間／位置／姿態資料中斷或跳躍，會結束該次練習。實際位置與速度、姿態與角速度需一致，不接受瞬移、重貼時間戳或把分開弧線拼成五圈。

## 示範與歷史成績

示範以正常搖桿輸入通過同一套飛控及物理錄製，不覆寫飛行中的位置或姿態，不接管真人操作。它會先找到目標、持續朝塔完成五個完整圈，圈數到 **5／5** 後才實際向塔外飛離，再恢復控制。本版錄影約 106.62 秒；第五圈約在 99.93 秒完成，飛離與控制確認後約 105.68 秒達成九步。預設半速觀看約需 3 分 33 秒，也可直接點第一圈至第五圈與最後離塔章節。獨立播放進度根據保留樣本與本課 evaluator 的實際觀察建立；暫停、選章節、變速或向後拖曳時，機體、搖桿、字幕、指標、圈數與勾選保持同一時間。結尾應顯示 **9／9**；往回看時會退回當時的進度。

課程仍使用 `orbit` ID，上次選課不需遷移。舊規則 **4** 是三步原型，保留原有 raw 紀錄、成績、次數及 context；新地面九步、五圈教學使用規則 **6**，分開累積次數、最近與最佳結果。讀取不清空、不覆寫，也不把舊完成直接轉算為新課完成。其他已核准課程及 L00 觀念標記保留。觀看、重播及章節操作均不寫入真人結果。未發布的單圈初稿已被本次五圈要求取代，其檢查不能當作五圈版驗證。

## 人工核對清單

1. 頁首是本輪版本；選課及示範名稱為 L15 正刷鍋。開始練習由實際地面等待明確解鎖，不自動在空中開始。
2. 觀看示範：參考目標清楚可見，機頭持續朝向它，第一圈至第五圈依序完成。**未到 5／5 不改出**，之後實際向外離塔至少 3 m 再恢復控制；結尾 9／9，章節、半速、暫停、倒退及退出保持同步。
3. 自行起飛至約 10 m，進入約 15 m 半徑，任選左繞或右繞；目標留在視野並持續朝塔完成五個完整圈，再從第五圈完成時的半徑向外飛離至少 3 m 並恢復控制。過程無須貼線或降落。
4. 只完成一圈、未滿五圈提前退出、原地偏航或反覆同一段來回，不應完成課程。五圈後只放慢／懸停而未實際向外飛離，也不應完成最後一步。一般偏離後能看懂首次原因、回到環繞區並重新準備；舊勾選不直接完成新五圈。
5. 高度／XYZ、環繞角、5／5 圈數、半徑與朝向指標清楚；可從 Chase 或自由鏡頭辨認路線，鏡頭操作不改飛機。
6. 結果與次數重新整理後保留；其他課程紀錄仍在。舊規則 4 原型紀錄留在原 scope，不會直接顯示為新課完成；看示範不增加次數。
