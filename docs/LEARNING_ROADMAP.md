## 產品目標與完成定義

讓零基礎使用者在桌面瀏覽器中，依序學會控制、起降、基本航線、失誤恢復與花飛，並能從每次練習知道下一次如何改善。

第一個對外試學版本的主要任務：使用者不需要旁人口頭指導，就能完成設備設定、理解四軸與 Acro 回中特性、起飛、懸停、短距離飛行與降落；失敗後能理解提示並重試。

各課容許範圍、時間、速度、分數與熟練次數均先視為原型參數，需經新手試學及有經驗飛手試飛校準。自動化測試通過、示範播放成功與真人學會，分開記錄證據。

- 保留既有 Coordinated Turn、Split-S、Orbit／刷鍋的穩定 lesson ID；舊 Hover 的 ID、evaluator 與歷史資料保留，但教學入口併入 L01，不再獨立選課。

- Acro／Actual Rates、PID、固定步長模擬，以及唯一飛行 runtime／requestAnimationFrame 擁有者。
- 依實際已解鎖飛行狀態與軌跡判定的 evaluator、checkpoint、結果與重試。
- 有容量限制的軌跡／回放、不可變樣本、增量計算與低頻 React 狀態發布。
- 既有本機校正、調參、進度資料，以及慢放、拖曳時間軸、鏡頭切換等回放能力。
