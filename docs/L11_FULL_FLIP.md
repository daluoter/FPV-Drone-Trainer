# L11 前後翻轉：試用與驗收

本輪頁首版本：**2026.10.24.3**。課程 ID：`full-flip`，規則 **6**。本課從地面自行起飛，沿俯仰方向完成一次前翻或後翻，再恢復空中控制。前翻與後翻任一方向完成即可，不要求同次連做兩種方向。**軟體與瀏覽器檢查已通過，仍待使用者人工試飛驗收**；L01～L10 的既有功能核准保留。

## 先看前翻與後翻示範

1. 更新並重新啟動本機網頁，確認頁首版本；使用預覽模式時需先重新建置，見 [更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)。
2. 選「L11 前後翻轉」，分別開啟「L11 前翻示範」及「L11 後翻示範」。L00 的「俯仰」是基本控制觀念示範，和這兩段完整翻轉分開。
3. 示範預設 **0.5×**。左側「示範進度」使用該段示範自己的六步，不沿用真人練習進度。
4. 觀察準備、倒置、完成一圈及恢復的先後順序；可以暫停、慢放、拖曳、切換鏡頭及點章節重看。點章節會先停在該段開頭，再按播放觀察。
5. 播放到結尾應顯示 **6／6**；往回拖曳時，勾選與目前步驟也應回到當時狀態。高度、翻轉進度、角速度及搖桿同步，暫停時保持固定。
6. 按「結束示範」回到原練習，真人結果與次數保留，觀看示範不增加成績。

兩個方向的示範由實際控制輸入通過同一套飛控與物理模擬錄製，再交給同課判定核對。錄製控制只產生示範，不接管真人飛行，也不逐段覆寫姿態製作成功動作。

## 自己練習的六個步驟

按「開始課程」，倒數後保持低油門，明確解鎖，再自行起飛。建議高度約 **10 m**，至少 **8 m** 才能準備翻轉。機腹朝天稱為「倒置」；這與後續課程中保持正飛、向機尾方向移動的「後退飛行」分開。

| 步驟 | 要做的事 | 觀察重點 |
| --- | --- | --- |
| 1 | 地面開始 | 在起飛區實際接地，高度約 0 m。 |
| 2 | 自行起飛至練習高度 | 升至至少 8 m，建議約 10 m，留出掉高與改出空間。 |
| 3 | 翻轉前準備 | 回到接近水平，減緩旋轉與漂移，依提示準備 0.1 秒。 |
| 4 | 通過倒置姿態 | 選前翻或後翻，沿同一方向持續俯仰旋轉，讓機體實際翻面。 |
| 5 | 完成一圈翻轉 | 繼續後半圈；接近正飛時提早回中與修正，減緩殘餘旋轉。 |
| 6 | 恢復正飛與控制 | 保持空中，減少傾斜、升降與水平漂移，確認 0.2 秒。 |

看到準備完成後，可先適量加油取得上升餘裕，再進入翻轉。倒置時適度收油，避免推力持續朝地面；接近正飛後補回推力並主動修正姿態。搖桿回中只要求停止旋轉，不會自動把機體回平。

先選一個方向，使用明確且連續的俯仰輸入完成一圈。很小的桿量會延長側飛與倒置時間，也會消耗更多高度。先看半速示範理解節奏，再依校正後的控制方向操作。成功後不需降落、回原座標或朝向原方向。

## 本版判定範圍

| 條件 | 本版範圍 |
| --- | --- |
| 練習區 | 起飛點水平半徑 80 m。 |
| 動作前準備 | 高度至少 8 m；傾角 ≤25°、機體旋轉速度 ≤120°/s、水平速度 ≤8 m/s、升降速度在 ±3.5 m/s，確認 0.1 秒。 |
| 完整翻轉 | 同一次有效動作經過傾角至少 150° 的倒置，沿同一方向淨旋轉 **360° ±20°**，再回到傾角 ≤30° 的正飛姿態。 |
| 空中恢復 | 高度至少 1.5 m；傾角 ≤30°、機體旋轉速度 ≤120°/s、水平速度 ≤8 m/s、升降速度 −2.5～+4 m/s，連續確認 0.2 秒。 |
| 時間 | 引導練習不限時；能力挑戰 300 秒，倒數與等待解鎖不消耗挑戰時間。 |

判定累積連續四元數姿態沿俯仰軸的有方向增量，並核對實際機體角速度。**前翻為正、後翻為負**；本圈進度顯示該次有效淨旋轉量的大小。半圈後原路翻回會互相抵消，不能靠左右橫滾、偏航、只操作搖桿、只有角速度讀值或姿態突變取得完成。

條件容許合理漂移，不要求精準懸停；仍需有連續、真實的一圈及後續空中恢復。上述數值是模擬器原型參數，依使用者試飛回饋校準。

## 中斷與重新準備

- 接地、低於 1.5 m、離開半徑 80 m、混入過多其他軸旋轉、超轉或反向折返，會使當前動作證據失效。先回到區內及足夠高度，重新準備，再完成新的一圈。
- 先前 checkpoint 里程碑可以保留，但中斷後不能只靠回平，省略新一圈的倒置與完整旋轉。
- 最近重練原因顯示觸發當時的高度、距離或角度；依實際原因改善，不只顯示通用「重新開始」。
- 墜毀、解除解鎖、失焦／斷線、重設、無效樣本及時間／路徑不連續會停止本次練習。重試清空本次步驟，回到地面自行起飛。
- 翻轉儀表與高度／XYZ 常駐顯示；示範時讀取錄影及獨立進度，退出後恢復真人狀態。
- `full-flip` 使用獨立 ID 與規則 6；L00 觀念示範、L10 完整橫滾及舊課成績不轉算為本課完成。

## 集中人工核對

- 課名是否只有中文；選課是否有 L11，示範工具列是否可分別開啟前翻與後翻。
- 開始課程是否在實際地面；明確解鎖後能否自行起飛至準備高度。
- 兩個示範是否各自完成六步；暫停、章節、前後拖曳、慢放及換鏡頭是否保持同步。
- 能否以前翻或後翻完成一圈並恢復控制；提示是否容易理解，難度是否合適。
- 半圈原路翻回、橫滾或偏航是否保持未完成；落地停住是否不能代替空中恢復。
- 中斷原因是否具體；回區或爬升後是否仍要求重新準備及完整一圈。
- 重載是否保留本課結果與次數；觀看示範是否不增加成績，L01～L10 及既有進階原型紀錄是否保留。
- 翻轉進度、角速度、傾角、高度、XYZ、字幕及步驟是否同步且不互相遮擋。
