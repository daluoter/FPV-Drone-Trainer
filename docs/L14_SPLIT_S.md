# L14 破S：試用與驗收

本輪版本：**2026.10.27.2**。課程依使用者要求由「翻轉下降」改名為 **破S**，保留 `split-s` ID、規則 **6**、地面起飛八步教學、獨立示範與原有成績。本輪在路徑之外加入可辨認上方與下方的參考結構，幫助理解倒置、下降與反向改出的空間關係；相關完整自動化、Lint、嚴格建置與正式產物瀏覽器檢查均已通過。**L13 大迴旋已人工驗證通過，L14 破S 仍待人工核對**，詳見 [驗證紀錄](LEARNING_VALIDATION.md)。

## 入口與練法

1. 更新本機網頁並確認頁首版本，預覽模式先重新建置，見 [更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)。
2. 選擇 **L14 破S**，觀看 **L14 破S示範**。桌機示範列可橫向捲動，手機會換行；本課有自己的八步進度，觀看不增加真人成績。
3. 開始課程、倒數後保持低油門，明確解鎖，再自行起飛。至少 **15 m**，建議約 **25 m**，留出下降半圈與拉平的空間。
4. 建立前進速度，先向左或向右橫滾半圈，讓機體實際倒置。這一段先完成橫滾，再接俯仰；不要直接用後翻替代。
5. 倒置時適度收油，接著向後拉俯仰，讓實際航跡向下繞過半圈，機頭與移動方向逐漸轉向來路。
6. 保留下方空間，接近正飛時提早回中、減緩旋轉並補回油門，主動拉平改出。保持空中控制即可，不必回原點、精準懸停或降落。

本課是「先橫滾成倒置，再下降半迴圈反轉方向」。正飛水平迴轉、只偏航轉頭、在地面轉向、原地後翻或倒置後反向滾回，都不能代替完整動作。

## 參考物與路徑

場景保留下降半迴圈與出口路徑，並加入有厚度的橙色參考門架：位在起飛點正前方約 40 m，橫樑中心離地約 18 m，兩側立柱之間有寬大的開口。參考路徑從約 25 m 的橫樑上方進場，在橫樑後方倒置並下降，再朝來路從橫樑下方改出，讓上方與下方的關係容易辨認。可用 Chase 或自由鏡頭，暫停示範後從旁觀看。

參考物用於辨識位置、高度及方向，本輪不新增碰撞或穿過固定缺口的通關要求；仍可依原本寬鬆範圍完成動作。

## 八步與觀察指標

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 起飛區實際接地，低油門明確解鎖。 |
| 2 自行起飛至下降餘裕高度 | 離地至少 15 m，建議約 25 m。 |
| 3 建立前進速度 | 前進至少 3 m/s，姿態接近水平，短暫準備。 |
| 4 橫滾半圈至倒置 | 左右任一方向都可，觀察實際半圈橫滾與倒置姿態。 |
| 5 拉出下降半迴圈 | 倒置後沿俯仰向後拉，實際下降至少 3 m。 |
| 6 實際反轉飛行方向 | 機頭與速度逐漸轉向來路，實際反向移動至少 1.5 m。 |
| 7 拉平恢復正飛 | 完成下降半圈，機頭方向改變至少 140°、垂直航跡轉角至少 100°，恢復正飛。 |
| 8 恢復正飛與控制 | 留在空中，減緩旋轉與升降，連續確認 0.2 秒。 |

飛行畫面保留高度與 XYZ，另顯示本次橫滾、倒置後俯仰及下降高度。本版橫滾容許 145°～235° 且需實際倒置，倒置後俯仰接受 145°～225°。兩軸分開觀察，避免只看機體最終姿態就誤判完成；XYZ 是固定場地座標，反向飛行則相對本次進場方向。

## 寬鬆範圍與中斷

| 條件 | 本版範圍 |
| --- | --- |
| 練習區 | 起飛點水平半徑 150 m。 |
| 最低空中恢復高度 | 離地至少 1.5 m。 |
| 恢復姿態 | 傾角不超過 35°，機身旋轉速度不超過 140°/s。 |
| 恢復移動 | 水平速度不超過 15 m/s、升降速度 −4～+5 m/s，連續 0.2 秒。 |
| 時間 | 引導練習不限時，能力挑戰 300 秒。 |
| 位置容許 | 不要求固定圈徑、精準出口、返回起點或降落。 |

接地、過低、出區、明顯離軸／過轉／反向或航跡中斷，會使本次動作失效。畫面保留當時的原因及相關數值，回到安全高度後仍能知道先前缺少哪段。已勾選里程碑不代替新動作證據；重新準備後仍須完成新的半圈橫滾、下降半迴圈與空中改出。墜毀、無效或中斷資料、解除解鎖則結束本次練習，再練一次由地面開始。

## 示範與歷史成績

示範以實際控制輸入通過同一套飛控及物理錄製，不覆寫飛行中的位置或姿態，也不接管真人飛行。示範有自己的八步與章節，預設半速；暫停、拖曳、慢放及向後回看時，姿態、搖桿、提示、數值與步驟同步。結尾應顯示 **8／8**；往回拖曳會退回當時的進度。退出後恢復原本的真人課程，仍需自行解鎖。

課程仍使用 `split-s` ID，上次選課不需改名。舊高空原型使用規則 **4**、五個步驟，結果留在原有成績 scope；新地面教學使用規則 **6**、八個步驟，分開累積次數、最近與最佳結果。讀取不清空、不覆寫、不把舊完成轉算為新課完成；無須清除本機儲存。L13、其他課程及觀念題紀錄也各自保留。

## 日後人工核對清單

1. 頁首版本、L14 破S 選課及示範入口正確；開始練習由地面等待明確解鎖，參考物與原本路徑均可辨認。
2. 示範依序展示半圈橫滾、倒置、下降半迴圈、方向反轉及空中改出，結尾八步完成；暫停、章節、倒退與退出同步。
3. 自行起飛至約 25 m，帶前速進場，選左或右橫滾成倒置，再向後拉俯仰完成下降半圈並拉平。
4. 只做正飛迴轉、偏航或後翻不會通過；正常完成不需降落、精準回原點或貼著路線。
5. 中斷時能看懂原因及下一步；重新準備不會沿用舊倒置標記直接通過。高度、XYZ 與本課儀表清楚可見。
6. 新規則成績重新整理後保留；舊高空原型成績仍在原 scope，觀看示範不增加任何課程次數。L13 基礎版已獲核准；若要複核提高起步高度，可參考 [L13 清單](L13_POWER_LOOP.md#人工核對清單)。
