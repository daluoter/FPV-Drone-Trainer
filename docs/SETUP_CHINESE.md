# 設備校正與調參中文化

版本：**2026.11.11.1**。範圍為「設備與校正」及「進階調參與舊版紀錄」中的兩個介面；原本的開發階段標題改成「設備與校正」及「飛行參數調整」。這項介面人工驗收仍待回覆。

## 已確認用語

使用者於 2026-11-11 明確選擇中文說明加原術語：

| 原術語 | 顯示用語 |
| --- | --- |
| Actual Rates | 角速度曲線（Actual Rates） |
| Center Rate | 中心靈敏度 |
| Max Rate | 最大角速度 |
| Expo | 曲線彎曲程度（Expo） |

中心靈敏度描述搖桿接近中央時的反應，不表示回中後機體仍會自行旋轉；最大角速度使用 °/s。橫滾、俯仰、偏航與油門沿用既有四軸用語；搖桿死區、正規化、濾波、回中穩定性及 PID 參數使用中文說明，保留 PID／FPV／FOV、P／I／D、軸符號與單位。設備原名及瀏覽器提供的識別資料保留。

## 使用與人工核對

1. 確認頁首版本 **2026.11.11.1**，按「設備與校正」，檢查設備選取、八步校正進度、原始訊號、處理後通道、方向反向、死區、回中報告與設定保存說明皆可理解。
2. 連接控制器，依中文步驟收集中心訊號、逐軸行程、確認方向及測試回中；檢查斷線、移動不足、多軸同動與不穩定提示能指出原因及數值。
3. 展開「進階調參與舊版紀錄」，確認角速度曲線、機體質量／馬達／阻力、PID 與鏡頭設定的欄位、圖表與按鈕均有中文說明。
4. 調整與套用設定、恢復預設值、重新整理，檢查保存與重設提示；課程倒數或練習時，設定鎖定規則維持。
5. 檢查桌面及窄畫面的按鈕、表格與數值可讀；舊校正、回中報告及調參資料仍可讀取。

中文化只改變呈現文字，原有校正流程、方向、數值範圍、解鎖條件、設定格式與儲存內容沿用。英文領域驗證訊息及舊回中報告在畫面顯示時翻譯，原始原因與數字保留。軟體與瀏覽器執行結果另見 [驗證紀錄](LEARNING_VALIDATION.md)；瀏覽器模擬設備的測試不視為實體遙控器驗收。
