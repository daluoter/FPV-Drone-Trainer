# L17 後退飛行：試用與驗收

本輪版本：**2026.10.28.2**。課程 ID：`backward-flight`，規則 **6**。使用者已核准開發本課；1233 項完整測試、Lint、嚴格建置及 54 項正式產物瀏覽器檢查均已通過，**使用者於 2026-10-28 明確回覆 L17 審核通過**，對應 `2026.10.28.2`／`43b0d17` 交付脈絡。先前 L01～L15 與自由鏡頭核准保留，其中 L15 五圈及實際離塔版本於 2026-10-28 明確人工通過。後續 `2026.10.29.1` 依新指示加入 [L16 倒刷鍋](L16_REVERSE_ORBIT.md) 的仰視三圈教學，L17 本課驗收與成績保留。

本課的後退飛行是「先正向前進，再偏航約 180°，機腹仍朝下，讓機頭朝向來路，飛機沿原來方向繼續移動」。它練習分辨機頭與實際速度方向；原地轉頭、轉頭後停住，再改朝新機頭方向前進，都不能代替這段後退飛行。

## 入口與練法

1. 更新本機網頁並確認頁首版本。預覽模式先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)；不用清除本機紀錄。
2. 選擇 **L17 後退飛行**，先觀看 **L17 後退飛行示範**。示範有獨立七步與章節，預設半速；觀看、暫停、倒退與退出不增加真人練習次數或成績。
3. 開始課程、倒數後保持低油門，明確解鎖，從實際地面自行起飛至約 **10 m**。最低起飛確認高度為 **4 m**。
4. 沿寬走廊先建立前進速度。保持機頭大致朝移動方向，以少量前傾建立前速，再回到較平穩的姿態。
5. 保留向前的動量，用偏航向左或向右轉頭約 **180°**；配合油門守住高度。此時機腹仍朝地，機頭朝向來路，實際移動仍延續轉頭前的方向。
6. 觀察後退速度與距離提示，維持一小段相對機頭向後的飛行。有效後退淨距至少 **3 m**、有效時間至少 **0.6 秒**；無須長距離、精準高度或貼線。
7. 完成後受控減速：相對後退路線達標當時的水平速度至少降低 25%，且不超過 2.5 m/s；也可再轉頭讓機頭朝實際移動方向，帶回接近水平、減緩升降與旋轉。空中恢復控制後完成，無須降落、返回原點或停在指定位置。

轉頭時視野轉回來路，但飛機不會因偏航立即改變移動方向。後退飛行時前後俯仰造成的推力方向也會跟著機頭改變；先用小量輸入觀察速度，避免因畫面反向而大幅修正。

## 參照物與儀表

場景提供寬闊方向走廊與來向／去向參照，讓轉頭前後都能辨識路線。這些標記只幫助觀察方向，沒有新增實體碰撞、窄門或精準穿越條件。

原有高度與相對起飛點 XYZ 保留。本課另顯示轉頭角度、相對機頭的後退速度及有效後退距離；機頭朝向與實際移動方向分開呈現。數值來自當時飛行資料，示範則使用當時的錄影觀察，未觀察的量測不以零值假裝完成。

可切換 Chase 觀察「機頭向後、路線仍往前」的關係；暫停示範後也能使用 Free / debug 與六向移動按鈕，見 [自由鏡頭操作](FREE_CAMERA.md)。鏡頭操作不改飛機、播放時間或課程成績。

## 七步與初版寬鬆條件

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 起飛區實際接地，等待明確解鎖後開始。 |
| 2 自行起飛至練習高度 | 自行離地達至少 4 m；建議約 10 m。 |
| 3 建立前進速度 | 機頭大致朝實際移動方向，建立真實前進動量。 |
| 4 保留動量轉頭 | 正立偏航約 180°，保留轉頭前的移動方向。 |
| 5 形成實際後退飛行 | 機體仍正立，實際速度朝機尾方向，不能只在原地轉頭。 |
| 6 維持後退路線 | 同一連續動作的有效後退淨距至少 3 m、有效時間至少 0.6 秒。 |
| 7 減速或轉回並恢復控制 | 比後退路線達標時至少減速 25% 且不超過 2.5 m/s，或把機頭轉回實際移動方向；恢復可控正飛並確認 0.25 秒。 |

| 條件 | 本版範圍 |
| --- | --- |
| 建議／最低起飛高度 | 約 10 m／至少 4 m。 |
| 動作高度 | 離地 4～30 m；短暫偏離容許修正，低於 1.5 m 立即中斷本次局部動作。 |
| 練習空間 | 起飛點水平半徑 150 m。 |
| 建立前速 | 至少 1.5 m/s，機頭與速度方向差不超過 45°，確認 0.2 秒。 |
| 轉頭 | 左右任一方向；朝向與進場反方向誤差不超過 60°，不用精準停在 180°。 |
| 後退姿態 | 機腹朝地，傾角不超過 70°。 |
| 保留原動量 | 沿進場原方向速度至少 0.5 m/s。 |
| 真正後退 | 朝機尾的速度至少 0.75 m/s，機頭與實際速度方向差至少 120°。 |
| 後退距離／時間 | 同一連續動作有效後退淨距至少 3 m、有效時間至少 0.6 秒。 |
| 恢復控制 | 傾角不超過 40°、機身角速度不超過 180°/s、升降速度 −4～+5 m/s。 |
| 恢復移動 | 達成 3 m／0.6 秒時固定當時水平速度；其後至少降低 25% 且不超過 2.5 m/s，或機頭重新朝向實際移動方向、誤差不超過 60°且水平速度至少 0.5 m/s；連續確認 0.25 秒。 |
| 時間 | 引導練習不限時，能力挑戰 180 秒。 |

前速、轉頭、後退與恢復必須來自同一段連續觀察。短暫偏離容許修正；原方向速度不足 0.5 m/s 持續 0.3 秒，或超出動作高度／後退條件持續約 0.75 秒，會中斷局部動作。機體傾角超過 70°、接地、低於 1.5 m 或離開練習區會立即中斷，需要重新建立「前飛 → 轉頭 → 後退」。已勾選的教學里程碑仍保留，但不能當作這次新動作的飛行證據；有效後退距離與時間會重新計算。畫面保留首次中斷原因與當時量測，直到有效新進場。

未墜毀接地、太低或離開練習範圍時，依畫面提示恢復位置並重新準備。墜毀、上鎖、重設，或連續時間／位置／姿態資料失效會結束本次練習。位置變化須與速度一致、姿態變化須與角速度一致，不能藉瞬移、重新貼時間戳、拼接前次動作或舊勾選通關。
