# 新手學習流程與資料契約

本文件記錄本批採用的產品預設、目前實作邊界及後續開發必須維持的規則。完整待辦仍以 [LEARNING_ROADMAP.md](LEARNING_ROADMAP.md) 追蹤；設計核對、程式完成、自動化驗證與真人試學是不同證據，不能互相代替。

## 已採用的產品預設

| 決策 | 本批採用的規則 |
| --- | --- |
| D01 平台 | 以桌面 Chrome／Edge、1280 × 720 以上視窗為首要目標。手機的課程介紹與示範觀看是後續適配目標，尚未宣稱完成手機驗收。 |
| D02 語言 | 主要教學流程採繁體中文；四軸、Acro、Arm 等術語在教學中附英文。既有進階設定與診斷的全部翻譯尚未完成。 |
| D03 飛行模式 | 從 Acro 觀念開始。新手 preset 降低 rates、採 10° 鏡頭與 90° FOV；不新增自動回平、定高或慢速物理。數值待真人試飛校準。 |
| D04 設備 | USB 遙控器為主要練習方式；鍵盤可體驗、開發與測試。輸入來源分開保存成績；一般手把的完整相容性另行驗證。 |
| D05 順序 | 顯示推薦順序與先備能力，允許跳課。先備資料是建議，不能成為隱藏的選課鎖。一次成功也不等於已熟練。 |
| D06 模式 | 產品分為引導練習、能力挑戰與自由飛行。預設為不限時引導練習，也可明確選能力挑戰；兩者使用相同物理、不同成績 context。示範／個人回放均有明確播放狀態。 |
| D07 資料 | 先使用瀏覽器本機保存；檔案匯出／匯入列後續實作。帳號、雲端同步、排行榜不在本批範圍。 |
| D08 發布 | 短期功能分支 → PR → main → UAT 驗收 → 手動 prod；不新增長期 `uat` 分支。正式站沿用 GitHub Pages。此規則不表示 UAT 部署已建好。 |
| D10 順序 | 先串起 v0.2 新手學習循環，再依試學回饋擴充 v0.3 航線與 v0.4 花飛。既有 Hover、Coordinated Turn、Split-S、Orbit ID 與能力保留。 |

D09 仍待選定：UAT 託管平台、網址與獨立 origin 尚未核對。GitHub Environment 名稱不會建立第二個網站；同一 `github.io` 網域的不同路徑也不會隔離 `localStorage`。發布工作必須在站台確定後接上，不能把本機 smoke 當作遠端部署成功。

## 使用者路徑

以下是畫面與狀態轉移應遵守的路徑；逐項完成度仍由 roadmap 與驗收紀錄追蹤。

| 情境 | 入口、下一步與復原方式 |
| --- | --- |
| 首次進站 | 「開始學飛」→ 認識 Mode 2、Acro 與停止方式 → 看同步示範 → 選 USB 校正或鍵盤體驗 → L01 起飛與定點懸停 → 結果與重試。目前預設選中 L01；L00 提供四個互動觀念題，全部答對後保存觀念完成標記，與飛行通關分開。看示範本身不完成觀念題。示範中可直接按題目旁「結束示範，繼續作答」，保留已選答案；飛行區也有明顯繁中退出入口。 |
| 回訪 | 讀取相同操控條件的本機進度；顯示已練次數與最佳結果，選課或自由飛行。不能因舊有 profile 存在就跳過當次 neutral／連線檢查。恢復上次選課與練習／挑戰模式，顯示「繼續練習」；成功結果提供推薦下一課，允許自由跳課。 |
| 無遙控器 | 可先看四軸、起飛、降落與直線示範，或明確選擇鍵盤體驗。鍵盤成績獨立保存，不能描述成已完成實體遙控器操作驗證。USB 引導入口始終可回到設備設定。 |
| 校正失敗 | 留在設備引導，按訊息重做中心、通道、端點、方向或 neutral 檢查。沒有有效 handoff 不可 Arm；不能用靜默假預設繞過。修正後回原課程，仍需明確解鎖。 |
| WebGL 初始化失敗／context loss | 顯示可見錯誤，runtime 解除解鎖並阻擋 Arm；可重試渲染。畫面恢復後仍需明確重新解鎖，不能在不可見的場景繼續評分。若瀏覽器根本不支援，提示改用支援 WebGL 的桌面瀏覽器；不宣稱軟體降級飛行已提供。 |
| 已熟練使用者 | 可跳選既有進階課，或進入自由飛行；自訂調參留在進階區。切換課程、設定、輸入與播放時仍遵守解除解鎖與重設邊界。 |

選課、目標、提示與 Arm／Disarm 在同一飛行工作區。UI 不可為了切換區塊建立第二個飛行 runtime 或第二條 requestAnimationFrame 迴圈。提供原生全螢幕及不支援時的提示，沿用 resize 渲染；飛行或待開始課程期間註冊原生離頁確認。瀏覽器可能要求先有使用者互動才顯示確認。全螢幕關閉若造成失焦，仍解除解鎖；完整小視窗及長時間操作另行驗收。

## 課程啟動、停止與播放

啟動採用同一條狀態路徑：

```text
READY
  └─ 開始：解除解鎖、套用課程場景與初始狀態
       → COUNTDOWN（runtime 層禁止 Arm，不評分）
       → WAITING_FOR_ARM（等待明確解鎖，不消耗挑戰時間）
       → 第一個有效 armed=true 固定步進樣本
       → ACTIVE（此樣本同時建立計時起點，elapsed=0 並開始評估）
       → SUCCESS／FAILED → RESULT → 重試／選課
```

- 高空課程準備時保持明確解除解鎖的初始姿態，固定步進時鐘持續前進；第一次成功 Arm 才釋放準備保持。普通自由飛行解除解鎖後仍遵守原本重力。重設、調參與播放退出會清除準備保持。
- 倒數、等待、無效樣本、缺少 armed 欄位與播放樣本不能產生成績。倒數期間若出現提早解鎖資料，必須先 Disarm，再明確 Arm；不沿用提早解鎖狀態。
- 第一個已解鎖樣本必須通過有限數值、timestamp、場景等檢查；評分以實際位置、姿態、速度與連續軌跡為準，不以搖桿腳本判斷成功。
- ACTIVE 後解除解鎖、失焦、斷線、runtime 重設或墜毀會停止該次挑戰；不能自動重啟或延續原成績。ACTIVE 中非有限狀態／接觸資料會終止該次練習。每個接受的樣本需有遞增物理 stepIndex，物理時間增量與樣本時間增量相符；重複狀態不能改貼時間戳累積停留。倒退時間樣本被拒絕，不能累積通關證據。
- 改選課程、切換模式、套用 preset／調參、進入示範或回放前先解除解鎖；課程倒數、等待、進行中鎖定調參。重試重新清空 checkpoint、軌跡與 session 狀態。
- 示範與個人回放共用播放／插值功能，但不是 live telemetry。機體、搖桿與字幕讀同一播放時間點；暫停、慢放與拖曳不能餵入課程 evaluator、改變真人飛行狀態或累積進度。退出播放後仍是未解鎖狀態。
- 本批示範來自模擬／可測試資料；不是經飛手核准的教學錄影，也不能證明真人能完成課程。

## 引導練習、能力挑戰與基礎課程

| 規則 | 引導練習（預設） | 能力挑戰 |
| --- | --- | --- |
| 計時 | 第一個有效已解鎖樣本起算，但不套用挑戰逾時。 | 各課原型時限仍有效，例如起飛 25 秒、直線與降落各 90 秒、L04／L05 各 180 秒、L06／L08 各 240 秒、L07／L09／L10 各為 300 秒（包含自行起飛及移動）。 |
| 一般偏離 | evaluator 明示 `recovery: restart` 時清空局部 checkpoint、停留與累積指標，顯示回到起點的提示；保留真實姿態、軌跡、整次時間與連續資料完整性檢查。 | 依課程明示規則重算停留或結束挑戰。 |
| 安全 | 墜毀、失焦／斷線／解除解鎖、重設、無效資料仍停止。 | 同左。 |
| 成績 | `mode: practice` 獨立保存，不計成相同條件的挑戰成績。 | `mode: challenge`，依實際 preset／完整設定／輸入分開比較；尚未宣稱已熟練或標準證照。 |

- L00：Mode 2、Acro 回中、推力與高度、停止／重新解鎖四個觀念題；錯答有解釋與重試，全部答對才保存知識完成。不是飛行能力認證，姿態微操作課仍可繼續擴充。
- L01（`takeoff`，起飛與定點懸停）：從實際起飛 anchor 受控離地，到 anchor Y + 2 m 附近連續定點懸停 1.5 秒；同時控制高度、位置、水平／垂直速度及傾角。原 L01 已包含這段懸停，本版合併教學名稱與入口，不另加舊 Hover 的 3.2 秒門檻。暴衝、只碰到高度或瞬移不能通關。詳見 [L01 試用清單](L01_TAKEOFF_HOVER.md)。
- L02（`straight-line`）：從實際地面自行起飛，依序穿過前方 3 m 藍圈、5 m 金圈、8 m 綠圈即完成。三個圈為垂直圓環，中心高度為地面上方 3 m，開口半徑 1.5 m，另有 0.1 m 邊緣容差。採連續線段與圓環平面交點判定，快速穿越也計入；不要求減速比例、入口速度、終點停留或先在起飛點懸停。漏圈可繞回該圈前方重新朝前穿過，保留已完成的圈。起點水平高度環是指引，不是額外通關門檻。
- L03（`landing`）：從實際地面起飛，實際支撐點離地至少 0.15 m，再飛往正前方 8 m 的另一個降落區。在藍色標記半徑 1.5 m 內由空中實際接地，且物理狀態未墜毀即完成。不再額外要求接地前 0.8 m/s、低速低傾角、精準進場或穩定停留。落在區外可原地再起飛，保留離地進度；在起飛墊停著、沿地面滑入或空中 Disarm 仍不算降落。
- L04（`direction-control`）：地面自行起飛後，依序完成右移、左移、前移、後移、向右偏航換向、依新朝向前移及右移，共 9 個 checkpoint。目標球半徑 1.5 m，另加 0.1 m 邊緣容差；以連續移動進入目標區判定，不要求速度或停留。前四個移動目標保持機頭大致朝原前方，換向後兩個目標以新朝向為準，容許朝向偏差 60°。偏航步驟在換向區內大致朝場地右側（誤差不超過 45°），且相對前一步記錄的朝向實際改變至少 45°，避免同一姿態重複計入。練習不限時，挑戰 180 秒；漏點或非墜毀接地保留進度，可就地再次起飛。

- L05（`coordinated-turn`，規則 5）：從實際地面自行起飛，依序通過右轉入口／彎中／出口，再通過左轉入口／彎中／出口，共 8 個 checkpoint。目標球半徑 1.8 m，另加 0.1 m 邊緣容差，中心為地面上方 3 m；連續線段穿越也計入。機頭大致順著各段方向，容許 70° 偏差；每個出口需要實際水平移動方向相對該彎入口，向指定方向改變至少 25°。使用速度或實際位移取得移動方向，不以搖桿腳本或原地偏航代替航線。沒有精準速度、停留或航廊重置要求；漏點及未墜毀接地保留進度。練習不限時、挑戰 180 秒。

- L06（`square-route`，規則 5）：實際地面準備及自行起飛後，依序通過四段直線中點與轉角／終點，共 10 個 checkpoint。沿邊長 12 m 的順時針方形回到起點上方：相對起飛點 X／Z 依序 `(0,-6)`、`(0,-12)`、`(6,-12)`、`(12,-12)`、`(12,-6)`、`(12,0)`、`(6,0)`、`(0,0)`。目標中心為地面上方 3 m，球形半徑 1.8 m、另有 0.1 m 邊緣容差；連續線段穿越也計入，機頭方向保留 70° 容差。不要求精準速度、停留、額外轉角數值或終點降落；依序完成四段的實際位置目標即可。漏點及未墜毀接地保留進度，練習不限時、挑戰 240 秒。

- L07（`figure-eight`，規則 5）：從實際地面自行起飛，依序完成中央入口、左圈三點、中央換向點、右圈三點、中央空中終點，共 11 個 checkpoint。中央位於起飛點前方 6 m；相對 X／Z 依序為 `(0,-6)`、`(-6,-12)`、`(-12,-6)`、`(-6,0)`、`(0,-6)`、`(6,-12)`、`(12,-6)`、`(6,0)`、`(0,-6)`。三個中央目標使用獨立 ID 及順序，不能提早取終點。目標中心地面 + 3 m、球形半徑 1.8 m、邊緣容差 0.1 m、朝向容差 70°；快速連續穿越也計入。不要求精準速度、停留、額外轉角數值或降落。漏點及未墜毀接地保留進度，練習不限時、挑戰 300 秒。

- L08（`wide-gate`，規則 5）：實際地面準備、自行起飛、依序穿過三道寬門，共 5 個 checkpoint。相對起飛點 X／Z 為 `(0,-8)`、`(0,-16)`、`(0,-24)`，中心地面 + 3 m、清楚開口寬 4 m／高 4 m，開口下緣地面 + 1 m、上緣 + 5 m。採連續線段朝前穿越目前門平面的交點判定；繞門、反向穿門及地面滑行不能代替通過。左柱、右柱、上樑、下樑皆為實體碰撞，物理以全機尺寸的保守包絡做跨步掃掠，碰框先由物理墜毀，再終止練習；轉角附近可能比畫面機體外形更早接觸。不額外要求速度、朝向、停留或降落，漏門及未墜毀接地保留進度，練習不限時、挑戰 240 秒。三道框架始終保留，只有當前門的指引亮起；切往自由飛行或其他課程會清除這組靜態碰撞場。詳見 [L08 試用與驗收](L08_WIDE_GATE.md)。

- L09（`basic-recovery`，規則 6）：地面自行起飛至至少 3 m，建議約 4 m，再由使用者產生並修正傾斜、下沉及漂移，共 8 個 checkpoint。每段在水平半徑 40 m 內、高度至少 3 m、機體角速度 ≤90°/s 的狀態準備 0.1 秒；其餘準備條件依段落分開，減少每次同時精準控制所有方向的要求。

  傾斜段準備為傾角 ≤12°、升降速度在 ±1.5 m/s，允許水平漂移；實際傾角 ≥15° 後，回到 ≤12° 並減緩旋轉。下沉段準備為傾角 ≤25°、水平速度 ≤3 m/s、升降速度 −0.2～+1.5 m/s；在高度至少 2.5 m 時下降速度達 0.5 m/s 後，減少下降至 0.2 m/s 內，或以 2 m/s 內向上修正，傾角容許 25°。漂移段準備為傾角 ≤20°、水平速度 ≤0.8 m/s、升降速度在 ±1.5 m/s；水平速度達 1.2 m/s 後，降低至 1.0 m/s 內、傾角 ≤20°、升降速度在 ±2 m/s。各恢復均需旋轉速度 ≤90°/s、保持空中且高度至少 1 m，在區內連續確認 0.25 秒。準備需在先前樣本確認，初始靜止或持續偏差不能直接通過。

  接地或過低使當前偏差失效，保留已完成前段；重新爬升、準備及產生該偏差後才能恢復。出區只暫停並重計準備／確認，已有效偏差保留。終止重試則清空本次步驟。引導練習不限時、挑戰 300 秒；不用回原 XYZ、固定朝向或長時間懸停。系統不施加 live 自動擾動、接管搖桿或自動回平。詳見 [L09 試用與驗收](L09_BASIC_RECOVERY.md)。

- L10（`full-roll`，規則 6）：從地面自行起飛，建議高度 10 m、準備至少 8 m，在起飛點水平半徑 60 m 內依序完成地面、離地、準備、倒飛、一圈橫滾與空中恢復，共 6 個 checkpoint。向左或向右皆可。準備 0.1 秒，傾角 ≤20°、機體角速度 ≤90°/s、水平速度 ≤5 m/s、升降速度在 ±3.5 m/s；確認後允許建立上升餘裕再進入動作。

  同一次有效動作需觀察實際倒飛傾角 ≥150°、連續四元數增量的有方向橫滾淨量達 360° ±20°，並回到傾角 ≤25°。姿態變化需與實際機身角速度相符；Yaw、Pitch Flip、半圈原路翻回、反覆搖晃與四元數正負號不能代替整圈。完成後在至少 1.5 m 高度保持空中，傾角 ≤25°、機體角速度 ≤90°/s、水平速度 ≤5 m/s、升降速度 −1.5～+3 m/s，連續確認 0.25 秒。

  接地、低於 1.5 m、出區、過度混入其他軸或超轉使當前動作證據失效；先前 checkpoint 里程碑可保留，但需重新準備及觀察新的一圈，不能用舊倒飛／整圈標記直接完成恢復。墜毀、解除解鎖、重設或無效／不連續資料終止本次；重試清空本次步驟。練習不限時、挑戰 300 秒，不要求降落、回原 XYZ 或長時間懸停。詳見 [L10 試用與驗收](L10_FULL_ROLL.md)。

課程 ID 及知識標記保留，推薦順序為起飛與定點懸停 → 直線穿圈 → 降落 → 側移與方向感 → 協調轉彎 → 方形航線 → 八字航線 → 寬門穿越 → 基礎失誤恢復 → 完整橫滾 Roll；L09 與 L01 合併／改號功能已有使用者人工核准，新 L10 尚待試飛，下一項為 L11 Flip。場景 `training-launch` 是實際幾何支撐地面的 COM 起點，地面起飛課程以它準備；起飛及懸停沿用已驗證行為。`landing-surface` 是正前方獨立落點與實際地面高度；低空航線高度以地面 + 3 m 設定，L09 建議高度為地面 + 4 m，兩者都不受自由飛行自訂高空 spawn 影響。接觸旗標與物理接觸解算器共用容差。既有地面撞擊／翻覆墜毀判定未調整；L08 新增的靜態門框碰撞只用於該課環境，其他參考圈／塔仍是教學標記。Split-S 的進入／改出門檻仍以相對地面高度判定。

L04 接在降落後、L05 協調轉彎前，可自由跳課。以同一個實際地面起飛點準備，目標中心為地面上方 3 m。相對起飛點 X／Z 位置依序是 `(4,0)`、`(-4,0)`、`(-4,-4)`、`(-4,0)`、`(-4,0)` 換向、`(0,0)`、`(0,4)`；只顯示當前亮起目標與朝向箭頭。FPV 的左右／前後／上下目標提示以目前機身朝向計算，與固定場地方向的 XYZ 顯示分開。重複位置仍按先前 checkpoint 與換向時的實際朝向推進，不能以原地轉頭代替其他移動。新課沿用規則版本 4、新 lesson ID 與空初始進度，不重算既有 L02／L03 的完成紀錄。

目前兩課的一般漏圈／落在區外均給出下一步，不清空既有進度或要求回原起飛點。其他課程使用局部重練時仍保存首次觸發原因，不讓下一幀的一般返回指引覆蓋；側欄「最近重練原因（當時數值）」到新次／重試／重設／換課才清除。接地前速度可用於觀察與歷史結果說明，不再是新版降落的額外否決條件。

飛行畫面常駐高度與明確標示的 X／Y／Z，不需開啟 Developer HUD，墜毀後仍顯示。高度為機體質心相對配置地面的公尺值，與直線課 3 m 目標相同；相對起飛點座標使用固定場地方向：X 正為右、Y 正為上、Z 負為前／正為後，不隨機頭轉向。位置原點是實際支撐地面的起飛點，與自由飛行可自訂的高空 spawn 分開。數值顯示到小數一位；缺少有效姿態時顯示「—」。回放採 ghost 姿態及該段錄影的場地設定，seek 更新、暫停固定；舊結果回放不能套用新飛行的地面高度或起點。

以上數值均為原型參數。軟體、自動化、使用者功能核准及飛手校準分開記錄。使用者先前已回報 L00 作答／重載及舊 L01／L02 沒問題，並依序核准舊 L03～L09。2026-10-24 回覆「L10 已通過人工驗證」，核准 `2026.10.23.6`／`b30806e` 脈絡的基礎失誤恢復；該課在本版改編為 L09，規則 6 與判定不變。使用者後續又核准 `2026.10.24.1`／`d518897` 脈絡的 L01 合併、入口移除、改號及紀錄保留。新 `2026.10.24.2` 的 L10 完整橫滾仍待人工驗收。確切本機 SHA、瀏覽器及輸入設備未另提供；不推定共通硬體／飛手項目已完成。歷史回報使用當時編號，本文件其他課程說明採目前編號。

## 獨立示範進度

目前已有的三種 L00 四軸示範及 L01～L10，共 13 種示範，均使用獨立的示範進度。課程影片依保留的實際飛行樣本與同課 evaluator 觀察到的 checkpoint 建立播放索引；L00 使用編排的教學動作章節。示範畫面會顯示自己的目前步驟、已完成及待演示項目，暫時取代真人練習的目標、勾選及結果呈現，退出後恢復原狀。

點選章節會暫停在該步開頭，按 Play 繼續；往回 seek 時勾選也退回對應時間，不沿用影片最末端的完成狀態。姿態、搖桿、字幕、場景指引與示範步驟共用播放時鐘。L09／L10 預設 0.5×。L10 的完整橫滾影片與 L00 小幅 Roll 觀念示範分開，依實際倒飛、整圈與恢復階段提供可跳看的章節；其控制僅生成示範，不接管真人。L09 各組留出 2 秒閱讀準備，以及真實偏差形成後 0.75 秒的觀察時間，再進入錄製的修正動作。此控制只生成示範，不接管真人飛行。

觀看、重播及章節操作不修改 TrainingSession、不寫入真人結果／完成次數，也不代表熟練。L01 同步示範包含起飛與連續定點懸停；本版沒有新增 Split-S／Orbit 的示範影片。

## 成績 context v1 與舊資料

每次新 UI 練習或挑戰在開始時固定一份 `TrainingAttemptContext`；課程中不得換輸入或設定後仍沿用舊條件。結果保存這份 context，互相比較必須完全相容。

| 欄位 | v1 值與意義 |
| --- | --- |
| `rulesVersion` | 目前 L09／L10 使用 `6`，以不同 lesson ID 保存；L05～L08 維持 `5`，其餘課程維持 `4`。L09 舊規則 5 的成績保留為歷史，不覆寫或重標成規則 6；新條件進度分開保存。舊 `1`～`5` context 仍可讀取。`trainingRulesVersionForLesson` 選定逐課目前版本，`loadCurrent` 合併各課對應版本；其他課程與模式、設定、輸入來源的隔離不變。 |
| `physicsVersion` | `1`；物理版本。 |
| `presetId` | `beginner`、`standard`、`custom`；只描述 rates／camera 分類，不能取代完整設定身分。 |
| `settingsFingerprint` | `settings.v1:` 加排序鍵的完整、有限 JSON 設定；保留精確身分，避免短 hash 碰撞。不代表加密或產物完整性驗證。 |
| `inputSource` | `controller` 或 `keyboard`。 |
| `mode` | `challenge` 或 `practice`；UI 可選兩值，預設 practice。 |
| `assistance` | `none`；未宣稱其他輔助已實作。 |

context 完整 canonical JSON 編碼後組成 scoped key：

```text
fpv-drone-trainer.training-progress.context.v1.<encoded-context>
```

其內容為 `{ schemaVersion: 1, context, progress }`；`progress` 仍是 `{ schemaVersion: 1, lessons }`。讀取時驗證 context 與 key 相符，再檢查分數、時間、checkpoint、有限指標與已知 lesson ID。新增已知課程用空紀錄補齊，不把未知或舊 placeholder ID 改標成新課完成。

舊 key `fpv-drone-trainer.training-progress.v1` 與既有校正／調參資料保留。舊進度可以顯示為「未分類舊版紀錄」，但不猜測其輸入、preset 或規則版本，也不併入新條件最佳成績。新的 scoped 結果不覆寫舊 key；毀損 JSON、未知版本、context 不符或儲存錯誤回報問題，不自動清空或用空文件蓋掉原資料。

學習偏好另外存於 `fpv-drone-trainer.learning.v1`，包含知識完成、最後課程及模式；損壞或未知版本不自動覆蓋。

UI 以 session ID 防止同一次結果重複保存；重試是新 session。進度 store 的一般 `recordResult` 呼叫本身不是去重資料庫，其他呼叫端也必須遵守一次寫入邊界。重載只恢復相同 context 的次數、最近與最佳，不代表新增了帳號同步、匯出／匯入或永久回放。新手 preset 的切換不默默覆寫原有自訂調參。

規則、物理、輔助或評分條件變更時，需更新相應版本／驗證器並明示相容性；不能只沿用舊 lesson ID 混合排名。UAT／prod 的站台隔離另外由 D09 決定，成績 context 不是部署環境的完整隔離替代品。

## 驗證與限制

純 evaluator／狀態機、mock UI、真實瀏覽器 WebGL、實體遙控器與真人試學分開記錄。自動化 fixture 成功僅證明規則與資料路徑符合該案例，不代表真機手感、飛行擬真度或教學效果已驗證。正式站 HTTPS／資源路徑與 UAT 發布亦需在實際部署後確認。


## 結果標記回放

終止結果首次出現時，擷取當次錄影及 checkpoint 的不可變快照，綁定 session ID。後續新飛行、時鐘重設或獨立示範不能替換這份結果的錄影。標記使用模擬絕對時間，再轉換為第一個保留影格起算的相對播放時間；點選後沿用原有 ghost、明確解除解鎖並暫停 seek，不餵入訓練樣本或新增進度。

若片段已被容量淘汰、沒有相符錄影或事件沒有對應影格，顯示原因並停用。事件晚於最後抽樣影格不超過 0.05 秒時，可跳至「結束前最後影格」，清楚標示實際時間差；不宣稱是精確失誤畫面。標記包含已完成步驟與課程完成／練習終止；一般局部重練尚未保存為歷史事件。錄影仍是本頁記憶體，重新整理不保留。
