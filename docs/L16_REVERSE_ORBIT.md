# L16 倒刷鍋：試用與驗收

本輪版本：**2026.10.29.2**。課程 ID：`reverse-orbit`，規則 **6**。使用者於 2026-10-28 指定初版為「仰視高處結構環繞三圈」，要求塔式起重機的高處機臂作為參照，並授權先開發試用；**L16 人工驗收待回覆**。L01～L15、L17 與自由鏡頭的人工核准及既有成績保留。

本課練習仰視高處機臂，真正沿同一方向環繞起重機三個完整圈，再飛離與恢復控制。「仰視」由當時 FPV 相機視線判讀，不以畫面中天空多、機頭偏航角或課程名稱直接推定倒置飛行。

## 入口與練法

1. 更新本機並確認頁首版本。預覽模式先重新建置，見 [本機更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)；不用清除舊成績。
2. 選擇 **L16 倒刷鍋**，先觀看 **L16 倒刷鍋示範**。示範有獨立七步、逐圈章節與半速；觀看、暫停、倒退及退出不增加真人次數或成績。
3. 開始課程、倒數後低油門明確解鎖，從地面自行起飛至約 **22.5 m**，約為 45 m 高塔身的一半。先辨認起飛點前方 **30 m** 的塔式起重機，以及離地 **45 m** 的高處參照。
4. 接近起重機旁，先在約 **10 m** 半徑建立可控側向移動，再抬高實際視線，把高處機臂留在 FPV 視野內。用機臂、塔身與吊鉤辨識自己繞到哪一側。
5. 保持同一環繞方向、持續仰視參考位置，依序完成第一、第二、第三圈。每圈完整 **360°**，同一連續動作淨繞行至少 **1080°**；左右任一方向均可，不必貼線或保持完美圓形。
6. 確認 **3／3 圈**後，朝起重機外側真正飛離至少 **3 m**；向外速度至少 **0.5 m/s**，再拉平並減緩升降與旋轉，確認 **0.2 秒**。原地懸停不能代替離開，不需要降落或回原點。

鏡頭通常有向上安裝角，鏡頭朝高處不等於機腹朝天。一般推力沿機身上方；保留向上的支撐分量，同時利用朝圓心的水平分量維持環繞。轉頭或改變機身方向後，前後左右輸入相對路線的作用也會改變，先以小量輸入觀察實際運動。本課不提供自動回平、位置吸附或真人操控代飛。

## 塔式起重機與儀表

場景自行建立 45 m 高塔身、24 m 長機臂、10 m 短配重臂、配重及吊鉤，從下方仰視時也能辨認結構。地面與空中寬鬆路徑、進場／高度標記及三圈階段提示只作參考；初版不新增起重機碰撞或精準穿門懲罰。

L16 的高度／XYZ 與課程儀表放在畫面下方，保留上方的機臂視野；練習中的任務及首次中斷說明放在模擬畫面下方。高度與相對起飛點 XYZ 保留；本課另顯示 **0／3～3／3 圈**、累積角度、繞行半徑及實際仰視／參照偏差。數值來自當時的飛行觀察；示範使用自己同時刻的錄影與判定，不沿用真人進度。可切換 Chase 或 Free / debug 觀察機體、推力姿態與航跡的關係，見 [自由鏡頭操作](FREE_CAMERA.md)。

## 七步與初版條件

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 起飛區實際接地，明確解鎖後才開始。 |
| 2 自行起飛 | 自行離地至至少 4 m，建議約 22.5 m（塔身高度的一半）。 |
| 3 仰視環繞進場 | 朝高處參考位置仰視，建立真正側向環繞。 |
| 4 第一圈 | 同一連續動作淨繞行至少 360°。 |
| 5 第二圈 | 同一連續動作淨繞行至少 720°。 |
| 6 第三圈 | 同一連續動作淨繞行至少 1080°。 |
| 7 飛離並恢復控制 | 第三圈後實際向外增加至少 3 m，保持向外運動並恢復控制。 |

| 條件 | 本版範圍 |
| --- | --- |
| 高處參照 | 起飛點前方 30 m、離地 45 m。 |
| 建議高度／半徑 | 約 22.5 m／約 10 m。 |
| 環繞高度／半徑 | 離地 4～30 m／4～30 m。 |
| 練習空間 | 起飛點水平半徑 150 m；低於 1.5 m 中斷局部動作。 |
| 真實環繞 | 側向速度至少 0.75 m/s，維持同一方向，不能只原地轉頭。 |
| 仰視 | 實際 FPV 前向視線仰角至少 35°；參照與視線夾角不超過當前 FOV 的一半。預設 FOV 90°時為 45°。 |
| 高低及推力關係 | 高處參照至少比機體高 6 m；機身傾角小於 85°，保留向上推力分量。 |
| 準備／修正餘裕 | 有效進場確認 0.1 秒；短暫偏離允許修正，連續約 0.75 秒失效會中斷本組。 |
| 三圈與離開 | 同一連續動作三個完整圈；第三圈後向外增加至少 3 m，徑向向外速度至少 0.5 m/s。 |
| 恢復控制 | 傾角不超過 40°、機身角速度不超過 180°/s、升降速度 −4～+5 m/s、水平速度不超過 20 m/s，確認 0.2 秒。 |
| 時間 | 引導練習不限時，能力挑戰 300 秒。 |

實際 FPV 視線包含機體姿態與目前鏡頭安裝角；切換 Chase／Free 只是觀看方式，不會移除仰視條件或改寫計圈。FOV 改變時參照容許角也隨實際設定計算，不以固定虛構鏡頭替真人得分。本次練習內需保持同一鏡頭設定；缺少有效鏡頭資料或中途改變設定，會停止本次判定並要求重試。

## 中斷、重練與成績

原地偏航、水平普通繞圈卻沒有仰視高處參照、直線擦過、反覆同一小段及拼接前次里程碑，都不能完成三圈。無效區間不增加正向角度，真實反向回走仍扣除；反向回走超過 45°會中斷本組。

一般偏離可先恢復位置與可控姿態，再重新準備本組；已完成的教學步驟保留，但本組圈數重新計算，仍須連續完整三圈。首次中斷的原因、當時高度、半徑、視線偏差及圈數保留，直到有效新進場。墜毀、上鎖、模擬重設或連續時間／位置／姿態資料失效會結束本次練習。

本課採新 `reverse-orbit` ID／規則 **6**，不從 L15 五圈或 L17 後退飛行轉算完成。既有原始紀錄、輸入來源、練習／挑戰、設定脈絡、偏好及 L00 觀念紀錄均保留。

示範由正常搖桿輸入與同一套飛控／物理實際錄製，地面重設後不在飛行途中覆寫姿態或位置。七步與三圈章節依錄影樣本的實際判定建立，不用字幕、播放時間或預排圈數代替飛行證據。

1. 頁首為 **2026.10.29.2**，選課及示範名稱為 **L16 倒刷鍋**；L17 仍保留，舊成績及完成標記存在。
2. 能從地面自行起飛至約 22.5 m，清楚找到塔式起重機與高處機臂，從下方仰視時也能認出長短機臂、塔身與吊鉤。
3. 示範結尾為 **7／7**、**3／3 圈**；逐圈顯示至少 360°／720°／1080°，第三圈後仍要實際飛離才完成最後一步。
4. 前後切換逐圈章節，暫停、半速與向後拖曳時，機體、搖桿、字幕、圈數及儀表保持同一時刻；觀看不改真人結果。
5. 自行嘗試仰視同方向繞行三圈，再向外改出。初版重點是可辨識的仰視航線及受控改出，不要求精準貼線或降落。
