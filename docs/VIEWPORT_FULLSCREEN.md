# 飛行畫面全螢幕

版本：**2026.11.09.1**。入口位於 LIVE SIM 飛行視窗的**右上角「全螢幕」**，取代原本放大整個工作區的「全螢幕練習」。本項介面調整的人工驗收仍待回覆。

## 使用方式

1. 先選控制方式、課程與鏡頭，或開啟要觀看的示範／回放。
2. 按飛行視窗右上角的「全螢幕」。只放大目前的飛行畫面，左右欄、下方控制列與回放面板不在全螢幕內。
3. 使用右上角的「離開全螢幕」或 **Esc** 返回，再操作選課、示範章節、播放速度或其他面板。

FPV、Chase、Free / debug 都沿用當時的鏡頭；切換全螢幕不會改選鏡頭。Free / debug 的滑鼠旋轉、平移、滾輪及聚焦畫面後的鏡頭按鍵仍可使用；可見的鏡頭移動按鈕位於原工作區。

高度／XYZ、課程儀表與必要的安全／回放提示保留。真人飛行時，右下角提供精簡 **Arm／Disarm／Reset**；解鎖仍需符合低油門、控制器與課程準備等原有條件，切換畫面本身不會自動解鎖。課程倒數、等待解鎖及練習中皆可放大畫面。要查看完整課程指引或結果，先離開全螢幕。

示範與回放也能全螢幕觀看，飛機、播放時間、暫停狀態及示範進度沿用原片段；觀看期間不顯示真人的 Arm／Disarm／Reset。全螢幕切換本身不會新增練習次數或成績。

## 瀏覽器不提供原生全螢幕時

系統會改用「視窗滿版」，讓飛行畫面填滿目前瀏覽器的內容區，並顯示說明。瀏覽器分頁與網址列可能仍可見。按 **Esc** 或「離開全螢幕」即可返回；返回後原本頁面可繼續捲動。原生全螢幕與視窗滿版都沿用同一張飛行畫布與模擬。

## 人工核對清單

1. 確認頁首版本為 **2026.11.09.1**，入口在飛行視窗右上角，正常畫面可辨認按鈕且不遮住高度／XYZ。
2. 進入後只有飛行畫面，左右欄與下方回放面板未被一併放大；飛行畫面比例正常，高度／XYZ、退出按鈕及精簡控制可讀。
3. 在地面進入後以 Arm 明確解鎖，試飛、Disarm 及 Reset 均使用正常流程。飛行中切換畫面也能繼續操作；若瀏覽器失去焦點，仍遵循原有上鎖規則。
4. 分別用「離開全螢幕」與 Esc 返回，確認原工作區、頁面捲動、鏡頭及課程進度正常；切換畫面沒有替你重設飛機或重新解鎖。
5. 暫停示範後進入及離開，確認飛機、時間與示範步驟沒有跳動；播放中的示範可以持續觀看，且不新增真人成績。
6. 若瀏覽器改用視窗滿版，確認說明可讀，Esc 與退出按鈕都能返回。桌面、手機直向與橫向均核對畫面及控制沒有溢出。

軟體與瀏覽器執行結果記錄於 [驗證紀錄](LEARNING_VALIDATION.md)。**L18 人工試飛仍待回覆，L16 倒刷鍋仍暫緩人工驗證，L19 既有人工核准保留**；本項顯示模式不更動課程規則或既有成績。
