依最新要求，前翻與後翻分成兩堂，大迴旋接在兩課之後；倒刷鍋仍接在正刷鍋後，俯仰倒帶仍接在橫滾倒帶後，形成 L11～L24 目錄。已驗收 L01～L10 不變，未對齊技巧繼續預留。

## L11：前翻

**學習目標：** 在足夠高度以前翻方向完成一整圈，經過倒置後恢復正飛與控制。

分段目標：

1. 從地面自行起飛，進入約 10 m 的練習高度與足夠改出空間。
2. 回到接近水平、減緩漂移與旋轉，依提示完成短暫準備。
3. 可先補油上拋，再以前翻方向連續旋轉，經過實際倒置；倒置時適度收油。
4. 繼續前翻至一整圈，回中減少殘餘旋轉，再補油恢復空中控制。

只接受前翻，不以後翻代替。錯向時保留當時方向提示，須先回正並重新準備，再完成正確的新一圈。半圈原路翻回、橫滾、偏航、落地停住或重設回正均不算完成。初版沿用原合併課的寬鬆位置與高度容許，不要求回原點或降落。使用獨立 `front-flip` ID 與規則 6，成績不從舊合併課轉算。

## L12：後翻

**學習目標：** 在足夠高度以後翻方向完成一整圈，經過倒置後恢復正飛與控制。

分段目標：

1. 從地面自行起飛，進入約 10 m 的練習高度與足夠改出空間。
2. 短暫準備後，可先補油建立上升餘裕。
3. 以後翻方向連續旋轉，經過實際倒置；倒置時適度收油。
4. 繼續後翻至一整圈，回中減少旋轉、補油並恢復空中控制。

只接受後翻，前翻不能完成本課。方向錯誤、動作中斷與恢復規則與前翻課一致；先備能力是推薦，不隱藏鎖課。使用獨立 `back-flip` ID 與規則 6，與 `front-flip`、舊 `full-flip` 分別保存結果。兩堂示範皆保留六步、半速、章節與獨立播放進度，觀看不寫真人成績。

## L13：大迴旋

**學習目標：** 帶速度進入，拉升、越過頂點、下降再拉平，讓實際航跡在垂直平面繞出一個大迴圈。

分段目標：

1. 從地面自行起飛至建議約 25 m，在寬闊區域建立前進速度，保留充足的下降改出高度。
2. 分別練習拉升上拋、越頂時的姿態與油門管理，以及下降後改出。
3. 串接成一個完整的空間迴圈。
4. 拉平恢復控制，觀察進場速度、迴圈尺度與改出高度的關係。

基礎版先在空曠區域配合大型路線標記練習，接受不同的迴圈大小與出口偏移，不要求完美圓形或精準回到原點。判定需有相符的上升、越頂、下降與位移；原地俯仰翻一圈、只上下升降、反向折返拼湊局部姿態，不能代替實際大迴旋。

本版使用獨立 `power-loop` ID、規則 6、八步進度與實際物理示範；門檻及人工清單見 [L13 大迴旋](L13_POWER_LOOP.md)。

繞樑或回穿門列為後續同課進階段，先完成實體障礙物、碰撞、進出方向及足夠改出空間的規格，再開放該段驗收。

## L14：破S

**學習目標：** 在足夠高度進入倒置，以下降半迴圈反轉航向，再拉平改出。

分段目標：

1. 從地面自行起飛，建立進場速度與足夠的下降餘裕。
2. 先單獨練習翻成倒置姿態，以及辨認此時的地面與改出方向。
3. 配合俯仰完成下降半迴圈，使實際飛行方向轉向來路。
4. 拉平、恢復推力與可控正飛。

初版接受較大的航線、高度及出口位置差異，先確認完整動作順序與未墜毀改出，不要求穿過窄門或落在指定點。只有偏航轉頭、未實際倒置、在地面轉向，或未走出下降半迴圈，都不算完成。

沿用既有 `split-s` ID，但教學與起點已改為規則 6；舊規則 4 的高空起點原型及成績留在歷史脈絡，不直接完成新課。場景保留進場高度、下降空間與出口路徑，並加入可從上方進場、下方反向改出的參考門架；參考物不新增碰撞或精準穿越要求。八步、數值門檻及人工清單見 [L14 破S](L14_SPLIT_S.md)。

## L15：正刷鍋

**學習目標：** 機體真正繞目標移動，協調機頭、側向速度與推力，再受控離開。

分段目標：

1. 從地面自行起飛，找到目標與寬鬆的環繞區域。
2. 先練習四分之一圈及半圈，觀察機頭朝向與實際路線的關係。
3. 選定一個方向，連續繞目標一圈。
4. 結束環繞並恢復可控的出場路線。

初版先接受合理的半徑、高度及鏡頭朝向偏差，不要求貼近目標、精準定距或連續多圈。原地打偏航、只從目標旁直線飛過、反覆在同一小段擺動累加角度，不能代替完整一圈。

保留既有 `orbit` ID。先沿用寬闊的參考目標，明確區分教學標記與真正會碰撞的物件；後續是否增加實體目標另列範圍。

## L17：後退飛行

**學習目標：** 先建立前進動量，再偏航約 180°，讓機頭朝向來路、飛機仍沿原方向移動，控制相對機頭的後退飛行。

分段目標：

1. 從地面自行起飛，沿寬闊走廊建立前速。
2. 練習保留原移動方向的轉頭，辨認畫面與速度方向改變的關係。
3. 在機腹仍朝地的姿態下，實際向機尾方向移動一段路線。
4. 受控減速或再次轉頭，恢復熟悉的前向飛行。

初版放寬轉頭角度、路線寬度及高度漂移，不要求長距離、窄門或精確停點。判定同時觀察機頭與實際速度方向；原地轉滿 180°、機頭轉回後才開始前進、只有短暫量測雜訊或靠瞬移產生位移，都不算後退飛行。

場景提供寬走廊、清楚的來向／去向及速度方向提示。此處的「倒飛」明確指後退飛行，與機腹朝天的倒置姿態區分。

## L19：重力門

**已與使用者對齊的核心流程：** 帶速進場 → 上拋 → 收油並配合橫滾、俯仰調姿 → 從頂部落入框內 → 從側面改出。這是動作定義確認，尚未有課程軟體或人工試飛驗收。

分段目標：

1. 從地面自行起飛，認識門架的頂部入口、內部空間及側面出口。
2. 拉開進場距離，向上拋射，取得到達頂部開口上方所需的高度與動量。
3. 降低油門並調整姿態，讓下落路線對準頂部開口。
4. 實際由上往下進入框內，再調姿對準側面出口。
5. 從側面飛出，恢復正飛與控制。

初版提供寬敞開口及清楚進出口，先要求依序完成「頂部向下進入 → 側面向外離開 → 可控改出」，不要求緊貼門框、固定轉動圈數或完整八字串接。略偏可在引導練習局部重來；墜毀仍須明確重設。

從側面直接穿門、只在框頂上方掠過、從底部向上穿入、進出次序顛倒、未進框就飛離，或藉重設／姿態覆寫取得正飛，都不算本動作。頂部及側面通過判定、可通行開口與實體框架碰撞必須使用一致的場景幾何，不能讓穿越容差允許飛過實心門框。

基礎課先完成單次流程；重力門八字另列未定義的進階段，待動作對齊後再規劃。

## L20：騎牆

**學習目標：** 沿牆建立速度，讓機腹朝向牆面、沿牆短暫前進，再恢復正飛。

分段目標：

1. 從地面自行起飛，練習平行牆面的進場路線。
2. 在足夠間距下側傾，使機腹逐漸朝牆，辨認高度與距牆變化。
3. 短暫維持上述姿態並沿牆向前移動。
4. 離開牆面、回正並恢復控制。

初版提案先以保留間隙的短暫通過為目標，放寬側傾角度、距離及高度漂移，不要求長時間等高飛行。是否需要實際接觸牆面尚待使用者核對，不能擅自把碰牆設為通關條件。

正飛平行牆面、僅機頭朝牆、原地側傾但沒有沿牆位移，不能代替騎牆。普通非 3D 機型在接近側立時向上推力減少，課程應容許下沉並提供改出空間，不增加自動定高、吸附牆面或額外推力來完成動作。

實作前需有真正的牆面碰撞與清楚安全區。若未來加入接觸版本，須另外定義可接受接觸、失速／墜毀及成績相容性，不能直接把牆改成無碰撞標記。

## L24：花飛串接

**學習目標：** 把已掌握的單項動作接成可控航線，學會安排每段進場速度、空間、姿態與退出方向。

分段目標：

1. 從地面自行起飛，查看本次組合、各段入口與最後出口。
2. 先完成兩個已驗收動作的組合，辨認第一段的出場是否能接上下一段。
3. 逐步增加動作數量或改變順序，同時保持連續可控飛行。
4. 完成指定組合並恢復控制。

初版從當時已交付並通過驗收的單項課程中選組合，不等待所有預留技巧才開始設計基礎串接。放寬銜接距離與時間，先要求指定順序及連續飛行，不做主觀風格排名或強迫貼地。

不能把不同次飛行、重設前後或示範回放的單項成績拼成一次串接；錯序、漏做、前一段未恢復可控就靠重設開始下一段，也不能算完成。引導練習可重練局部，完整串接的成績仍需來自同一次有效連續飛行。

## 共用場景與判定前置

- **地面與高度：** 每課從實際支撐地面、解除解鎖的狀態開始，由使用者明確 Arm 並自行起飛。相對地面顯示高度，不受自由飛行高空出生設定影響。
- **空間：** 為上拋、倒置、下降及改出預留足夠範圍，進出口、建議高度、方向及局部重試位置清楚可見。重設回到地面，不以隱藏瞬移補齊課程。
- **開口與碰撞：** 寬門、繞樑、重力門及牆面以實體幾何核對碰撞與可通行區域。重力門需辨識頂部向內與側面向外的實際通過次序；靠近中心點不能代替穿越。
- **實際證據：** 姿態、角速度、位置、速度及接觸狀態共同支持需要的動作。拒絕瞬移、姿態與運動不一致、過期樣本、失效數值、未解鎖、墜毀及重設跨段拼接等假完成路徑。
- **難度：** 初版優先給足空間與寬容差，確認動作、實際通過與可控改出。不能為了降低難度而取消碰撞證據、加入 3D 馬達、覆寫姿態或偷偷提供飛行輔助。

## 每課共同交付與驗收

每課開工時先列明初始狀態、進出路線、目標高度、容差、實際觀察量及局部重試行為，再進行實作。數值透過同一套模擬物理驗證，並在使用者試學後調整；規則改變時保留舊結果的版本脈絡。

1. 操作原理、先備提示、分段目標、常見錯誤及明確停止方式。
2. 從地面自行起飛的引導練習；練習與能力挑戰的成績及規則分開，等待使用者準備時不消耗挑戰時間。
3. 由實際控制輸入、飛控與物理產生的課程示範，不以逐段改寫位置／姿態製作成功路線。示範附獨立進度、可重看章節、暫停／慢放／拖曳及同步搖桿；播放不修改真人成績。
4. 保留高度、XYZ 與必要的課程儀表，顯示目前目標、已完成階段及下一步；錯因指出實際未滿足的條件，避免只顯示通用「重新開始」。
5. 真正的飛行判定與版本化成績保存；新課使用自己的穩定 ID，不重用其他動作的歷史 ID。
6. 適用的成功／接近成功／錯序／假完成驗證，以及真實瀏覽器中的場景、儀表、回放隔離、重試與進度重載檢查。
7. 交由使用者人工試飛核對動作、難度及提示，再標記該交付範圍通過。自動測試、示範完成及動作理解確認，均不代替功能人工驗收；共通硬體與飛手項目繼續獨立追蹤。
