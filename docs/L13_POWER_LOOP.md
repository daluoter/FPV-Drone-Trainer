# L13 大迴旋：試用與驗收

交付版本：**2026.10.27.2**。課程 ID：`power-loop`，規則 **6**。原版於 2026-10-27 獲人工核准；使用者於 **2026-10-28 明確回覆提高至 25 m 的大迴旋也驗證通過**，並核准自由鏡頭與 L14 破S 參考門架版本。本課建議進場高度與實際物理示範為 **25 m**，原本至少 6 m 的寬鬆門檻、動作判定與成績保留，見 [驗證紀錄](LEARNING_VALIDATION.md)。

本輪 `2026.10.28.1` 不更動已核准的本課判定；接續交付 [L15 正刷鍋](L15_ORBIT.md)，其人工驗收另行記錄。

## 入口與練法

1. 更新並重新啟動本機網頁，確認頁首版本；預覽模式先重新建置，見 [更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)。
2. 選擇 **L13 大迴旋**，先看 **L13 大迴旋示範**。淡色垂直迴圈是動作參考，不必精準貼線或回到原點。
3. 開始課程、倒數後保持低油門，明確解鎖，再從地面自行起飛。建議約 **25 m**，至少 **6 m** 才能建立有效進場。
4. 稍微前傾並配合油門建立前速，再拉機頭向上，讓實際航跡往上彎。持續同方向拉過頂點，倒置時適度收油，再沿下降段繞回。
5. 保留下方空間，接近正飛時提早回中減緩旋轉、補油並主動拉平，沿原進場方向向前改出。回中只減緩旋轉，不會自動回平或煞停。
6. 恢復空中控制即完成，不要求降落、精準懸停或回原座標。

本課練實際有高度與前後位移的大迴旋；L12 練的是機體後翻一圈。只在原地做後翻、純上下升降、水平轉圈或反向拼湊局部姿態，不能代替本課航跡。

## 八步與觀察指標

| 步驟 | 判定重點 |
| --- | --- |
| 1 地面開始 | 起飛區實際接地，低油門明確解鎖。 |
| 2 自行起飛至練習高度 | 離地至少 6 m，建議約 25 m。 |
| 3 建立前進速度 | 前進至少 3 m/s，姿態接近水平，短暫確認後開始本圈。 |
| 4 拉升並展開迴圈 | 本圈實際拉升至少 3 m，沿俯仰方向後拉，把航跡帶向上。 |
| 5 越頂通過倒置 | 本圈通過實際倒置，持續同一方向繞過頂部。 |
| 6 沿迴圈下降 | 越頂後向來路移動至少 1.5 m，從本圈最高點下降至少 2 m。 |
| 7 拉平向前改出 | 連續俯仰至少 325°，實際前後跨度至少 6 m、垂直航跡轉角至少 270°，並以至少 1 m/s 向前出場。 |
| 8 恢復正飛與控制 | 保持空中、減緩旋轉與升降，連續確認 0.2 秒。 |

「本圈俯仰轉角」觀察機體轉動，不能單獨代表飛出空間迴圈；拉升高度、前後跨度、越頂後退與垂直航跡另外判定。迴圈尺度從實際起拉算起，到下降後首次回正時固定；進場直線與回正後直飛不增加圈徑。若這時跨度不足，會說明當時數值並重開本圈，不能靠繼續直飛補成大迴旋。高度與 XYZ 顯示目前位置；XYZ 仍是固定場地座標，前進方向速度則相對本圈進場方向。

## 寬鬆範圍與中斷

| 條件 | 本版範圍 |
| --- | --- |
| 練習區 | 起飛點水平半徑 120 m。 |
| 改出高度 | 離地至少 1.5 m。 |
| 恢復姿態 | 傾角不超過 35°、機身旋轉速度不超過 140°/s。 |
| 恢復移動 | 水平速度不超過 15 m/s、升降速度 −4～+5 m/s，連續 0.2 秒。 |
| 時間 | 引導練習不限時，能力挑戰 300 秒。 |
| 位置容許 | 可有不同圈徑與出口偏移，不要求完美圓形或返回起點。 |

接地、過低、出區、過度偏離俯仰軸、過轉、反向折返或實際航跡停住，會中斷本圈。畫面說明原因，並保留事件當時的高度或距離；回到安全高度後，也能知道剛才錯在哪裡。先前勾選的里程碑可保留，但新一圈仍須重新進場並實際完成全部動作，舊倒置或改出標記不能直接通關。墜毀、資料不連續或解除解鎖會結束本次練習，再練一次從地面開始。

## 示範與紀錄

示範使用同一套飛控、物理及實際控制輸入錄製，不覆寫位置／姿態，也不接管真人飛行。播放有自己的八步進度，預設半速；暫停、慢放、章節、拖曳與向後回看時，姿態、搖桿、指標、提示及步驟保持同步。結尾應顯示 **8／8**，往回拖曳退回當時的進度。

觀看示範不保存真人成績；退出後恢復原本選課與真人步驟，仍需明確解鎖。真人結果與次數以 `power-loop` 獨立保存，既有前翻、後翻、歷史合併課與其他課程紀錄保持原本 ID 及規則脈絡。

繞橫樑、回穿門或狹窄障礙物的大迴旋，列為後續同課進階段；本輪空曠版不加入這些碰撞或路線要求。

## 人工核對清單

1. 選課及示範名稱是 L13 大迴旋；開始練習由地面等待明確解鎖，不在空中自動開始。
2. 示範確實往上繞出空間迴圈，而非原地翻轉；結尾八步完成，章節、半速、暫停、倒退及退出同步，真人成績不增加。
3. 自行起飛至約 25 m，帶前速拉升、越頂、下降，再向前拉平改出；確認目前目標能說明還缺哪段。
4. 在原地只做後翻，應保持空間航跡未完成；正常完成不需貼線、回原點或降落。
5. 中斷後能看懂原因與重練方式；回到高度不會沿用舊證據直接成功。高度、XYZ 及大迴旋指標清楚可見。
6. 成績與次數重新整理後保留；原課紀錄仍在。回報卡關時請附頁首版本、目前步驟及當時提示。
