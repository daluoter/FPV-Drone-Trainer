# 新增花飛課程：動作定義對齊

更新日期：2026-10-24。開發主清單見 [LEARNING_ROADMAP.md](LEARNING_ROADMAP.md)，課程分段與編排提案見 [花飛課程規劃](FREESTYLE_CURRICULUM.md)。本文件記錄動作理解與待確認事項；新增課號僅是規劃，尚未開始下一課實作。

## 已明確的動作需求

| 名稱 | 進場 → 核心動作／航線 → 出場 | 確認狀態 |
| --- | --- | --- |
| Flip 前／後翻 | 空中可控飛行 → 沿俯仰軸前翻或後翻 360° → 恢復正飛與控制。 | 原規劃課程；與 Power Loop 分課。 |
| Power Loop 大迴旋 | 帶前速進場 → 拉升、越過頂點、下降，航跡在垂直平面繞一圈 → 拉平恢復控制。 | 使用者明確要求新增；基礎迴圈與繞障礙物版本的範圍待課程規格核對。 |
| 倒飛／後退飛行（Backward flight） | 先有前進速度 → 偏航約 180°，機腹仍朝地，保留原本移動方向，使機頭朝向來路 → 控制後退飛行並改出。 | 使用者明確確認：「保持正飛姿態變成往後飛（就是打偏航 180 而已）」。 |
| 重力門 | 帶速進場 → 向上拋射至門架上方 → 收油，橫滾配合俯仰調姿、對準頂部開口 → 由上往下落入框內 → 從側面門洞改出並恢復正飛。 | 使用者於 2026-10-24 明確確認此基礎流程理解一致；不代表課程已實作或人工驗收。 |
| 騎牆（英文暫稱 Wall ride） | 沿牆帶速度進場 → 機腹朝向牆面，沿牆短暫前進 → 恢復正飛與控制。 | 使用者新增需求並描述機腹與牆面的關係；接觸牆體與否、角度、距離及時長尚未定義。 |

本輪「倒飛」明確指後退飛行，與機腹朝天的倒置姿態（Inverted）區分。後續教學與判定須同時觀察機頭與實際移動方向；偏航本身不會立即反轉速度，不能只用偏航轉滿 180° 代替後退飛行證據。L10 橫滾與 Split-S 所經過的機腹朝天姿態仍屬倒置。

騎牆依普通非 3D FPV 的實際推力設計短暫通過與改出。接近側立時垂直推力減少，會下沉；課程不預設能在垂直牆面旁持續等高停留，也不擅自把接觸牆面設為目標。上述物理說明不等於已核准的數值門檻。
