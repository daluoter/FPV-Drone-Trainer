# 新增花飛課程：動作定義對齊

更新日期：2026-10-29。開發主清單見 [LEARNING_ROADMAP.md](LEARNING_ROADMAP.md)，課程分段見 [花飛課程規劃](FREESTYLE_CURRICULUM.md)。使用者已核准 L01～L15、L17 與自由鏡頭；L15 最新核准對應 `2026.10.28.1`／`00a3c3d` 五圈及實際離塔版本。L17 後退飛行於 2026-10-28 明確人工核准，對應 `2026.10.28.2`／`43b0d17` 交付脈絡。本輪使用者指定 L16 為仰視高處機臂環繞三圈，並授權先開發試用；其功能仍待人工驗收。動作理解與功能驗收分開記錄。

## 已明確的動作需求

| 名稱 | 進場 → 核心動作／航線 → 出場 | 確認狀態 |
| --- | --- | --- |
| 前翻 | 向前俯仰翻轉 360°，再恢復正飛與控制。 | 規劃及實作 L11，使用 `front-flip`，後翻不能完成本課。 |
| 後翻 | 向後俯仰翻轉 360°，再恢復正飛與控制。 | 規劃及實作 L12，使用 `back-flip`，前翻不能完成本課。 |
| 大迴旋 | 帶前速進場 → 拉升、越過頂點、下降，航跡在垂直平面繞一圈 → 拉平恢復控制。 | 空曠版已交付，2026-10-27 使用者人工驗收通過；建議高度提高至 25 m，繞障礙版本另行定義。 |
| 破S | 從地面起飛並帶前速進場 → 先橫滾成倒置，再以俯仰帶入下降半迴圈 → 實際轉向來路並恢復正飛。 | 含參考門架版本於 2026-10-28 人工驗收通過。 |
| 正刷鍋 | 地面起飛進場 → 目標保持可見、機頭持續朝向目標，真正側移繞行同一方向至少五個完整圈 → 再改出並恢復控制。 | 使用者要求五圈（每圈 360°、合計 1800°）後實際離塔；本九步版本於 2026-10-28 人工驗收通過。 |
| 倒刷鍋 | 地面起飛 → 仰視塔式起重機的高處機臂，連續同方向真實環繞三個完整圈 → 向外飛離並恢復控制。 | 使用者於 2026-10-28 明確指定此初版範圍並授權開發；採 `reverse-orbit`／規則 6 七步，人工待驗。 |
| 後退飛行 | 先有前進速度 → 偏航約 180°，機腹仍朝地，保留原本移動方向，使機頭朝向來路 → 控制後退飛行並改出。 | 使用者明確確認：「保持正飛姿態變成往後飛（就是打偏航 180 而已）」，並指示本輪開發 L17；地面七步、可見方向參照及獨立示範採 `backward-flight`／規則 6，2026-10-28 使用者人工驗收通過。 |
| 重力門 | 帶速進場 → 向上拋射至門架上方 → 收油，橫滾配合俯仰調姿、對準頂部開口 → 由上往下落入框內 → 從側面門洞改出並恢復正飛。 | 使用者於 2026-10-24 明確確認此基礎流程理解一致；不代表課程已實作或人工驗收。 |
| 騎牆 | 沿牆帶速度進場 → 機腹朝向牆面，沿牆短暫前進 → 恢復正飛與控制。 | 使用者新增需求並描述機腹與牆面的關係；接觸牆體與否、角度、距離及時長尚未定義。 |

本輪「倒飛」明確指後退飛行，與機腹朝天的倒置姿態區分。後續教學與判定須同時觀察機頭與實際移動方向；偏航本身不會立即反轉速度，不能只用偏航轉滿 180° 代替後退飛行證據。L10 橫滾與破S所經過的機腹朝天姿態仍屬倒置。

騎牆依普通非 3D FPV 的實際推力設計短暫通過與改出。接近側立時垂直推力減少，會下沉；課程不預設能在垂直牆面旁持續等高停留，也不擅自把接觸牆面設為目標。上述物理說明不等於已核准的數值門檻。

## 接續工作

使用者已要求先規劃課程，其後再補齊其他技巧。已確認的重力門可列入規劃；倒刷鍋已獲三圈仰視環繞的初版開發指示。蛇形彎／水平刀旗、朱克翻滾、橫滾倒帶與俯仰倒帶繼續保留位置，尚不設 checkpoint、數值或英文對應。於對話中完成各動作核對後，再更新本專案的「進場 → 動作與航線 → 出場」規格。

主清單依使用者要求排列為 L11 前翻、L12 後翻、L13 大迴旋、L14 破S、L15 正刷鍋、L16 倒刷鍋；橫滾倒帶後仍為俯仰倒帶，串接順延 L24。原合併課於 `2026.10.24.3`／`92517a8` 脈絡獲人工核准；新拆課方向隔離與成績相容已通過軟體及瀏覽器檢查，使用者於 2026-10-26 明確回覆 L11、L12 驗證通過（`2026.10.25.1`／`44d673e` 交付脈絡）；L13 空曠版於 2026-10-27 人工驗收通過；提高至 25 m 的調整、自由鏡頭及 L14 破S 參考物版於 2026-10-28 一併人工核准。舊 `full-flip` 僅留歷史，不能直接完成任一新課；L14 保留 `split-s` ID 但升為規則 6，舊規則 4 成績留在原 scope。L15 地面九步、五圈沿用 `orbit` ID，但改用規則 6，舊規則 4 三步結果保留原 scope；該五圈及離塔版本於 2026-10-28 人工核准。L17 使用新 `backward-flight` ID／規則 6；其他既有 ID、規則與成績保留。

L16 的視線與機體方向分別判讀：鏡頭朝天空不直接代表機腹朝天；一般推力仍沿機身上方，只有保留向上與向心分量才能支持連續環繞。本版以實際相機視線與高處參照的關係、連續航跡及恢復證據判定，完整規格見 [L16 倒刷鍋](L16_REVERSE_ORBIT.md)。
