# L10 完整橫滾：試用與驗收

目前頁首版本：**2026.10.24.3**；本課首次交付與人工核准版本為 **2026.10.24.2**。課程 ID：`full-roll`，規則 **6**。本課從地面自行起飛，完成向左或向右的一圈橫滾，再恢復正飛與控制。使用者於 2026-10-24 回覆「L10審核通過」，本課已通過使用者功能驗收，對應 `2026.10.24.2`／`f1c8745` 的交付脈絡。未另提供實際本機 SHA、瀏覽器或輸入設備；L01 合併／改號與 L02～L09 的既有功能核准保留。

## 先看完整橫滾示範

1. 更新並重新啟動本機網頁，確認頁首版本；preview 需先重新 build，見 [更新步驟](DEVELOPMENT.md#confirm-the-updated-local-screen)。
2. 選「L10 完整橫滾」，按上方「L10 橫滾示範」。L00 的「橫滾」仍是四軸觀念示範，L10 會演示完整一圈與恢復。
3. 左側「示範進度」使用影片自己的六個步驟。可點「通過倒置姿態」或「完成一圈橫滾」暫停在該段開頭，再按 Play 看後半圈及停止旋轉。
4. 示範預設 **0.5×**，準備完成後留約 2 秒閱讀，再補油建立上升餘裕並橫滾。可暫停、換速度、拖曳及切換鏡頭，觀察地平線旋轉、Mode 2 搖桿、油門、離地高度與「橫滾練習數值」。
5. 播放到結尾應顯示 **6／6**。向前／向後拖曳時，目前步驟與勾選應同步；暫停後高度、旋轉速度及本圈進度應固定。
6. 按「結束示範」回到原練習，原本結果、次數與 checkpoint 保留，觀看不增加真人成績。

示範由實際 RC 輸入通過模擬器物理錄製，與真人使用同一份判定。錄製用控制只用於產生這段影片，真人飛行仍由使用者操作。

## 自己練習的六個步驟

按「開始課程」，倒數後保持低油門，明確 Arm，再自行起飛。建議高度約 **10 m**，至少 **8 m** 才能準備動作；翻到側面及倒置時，推力方向會改變，需要留出下降與恢復的高度餘裕。

| 步驟 | 要做的事 | 觀察重點 |
| --- | --- | --- |
| 1 | 地面開始 | 實際在起飛區接地，高度約 0 m。 |
| 2 | 自行起飛至練習高度 | 升至至少 8 m，建議約 10 m。 |
| 3 | 橫滾前準備 | 稍微減少傾斜、旋轉與漂移，依提示短暫準備 0.1 秒。 |
| 4 | 通過倒置姿態 | 選左或右，沿同一方向持續橫滾，實際通過倒置。 |
| 5 | 完成一圈橫滾 | 繼續後半圈，接近正飛時提早回中／修正，停止過大旋轉。 |
| 6 | 恢復正飛與控制 | 保持空中，減少傾斜、升降及側移，連續確認 0.25 秒。 |

可在看到「準備完成」後適量補油建立上升餘裕，再進入橫滾；倒置時適度收油，觀察推力方向及下降速度。不要在倒置處長時間停住。Acro 搖桿回中只要求停止旋轉，仍需自行判斷姿態及補回推力。

準備好後，用明確且連續的單向橫滾輸入完成一圈，接近正飛時提早回中；只用很小的桿量慢慢翻，會讓側飛／倒置時間變長、消耗更多高度。先以半速示範的搖桿與橫滾速度讀值理解節奏，再自行練習。

看到 6／6 完成結果即可 Disarm，不需降落、回到原 XYZ 或固定機頭方向。本課左右任一方向完成一圈即可，不必連做多圈。

## 如何判斷完成一圈

判定觀察連續四元數姿態的有方向橫滾增量，並核對實際機身角速度。左右反覆搖晃會相互抵消，不能把旋轉量絕對值加總成一圈；只操作搖桿、原地轉機頭、前後翻轉、半圈後原路翻回或四元數正負號變化均不代替完整橫滾。

同一次有效動作需實際通過倒置（傾角至少 150°），累積有方向的一圈（**360° ±20°**），並回到 **25°** 內的正飛姿態，再進入恢復確認。「本圈進度」是這次有效動作的有方向淨旋轉量大小；右滾速度顯示正值，左滾顯示負值。

| 條件 | 本版範圍 |
| --- | --- |
| 練習區 | 起飛點水平半徑 60 m。 |
| 動作前準備 | 高度至少 8 m；傾角 ≤20°、機體旋轉速度 ≤90°/s、水平速度 ≤5 m/s、升降速度在 ±3.5 m/s，短暫維持 0.1 秒。 |
| 空中恢復 | 高度至少 1.5 m；傾角 ≤25°、機體旋轉速度 ≤90°/s、水平速度 ≤5 m/s、升降速度 −1.5～+3 m/s，在區內連續維持 0.25 秒。 |
| 時間 | 引導練習不限時；能力挑戰 300 秒，倒數與等待 Arm 不消耗挑戰時間。 |

準備先在先前樣本確認，才接受新的橫滾動作；準備完成後可建立上升餘裕。條件保持寬鬆，不要求長時間精準懸停；這些仍是待試飛校準的模擬器原型參數。

## 中斷與重新準備

- 未墜毀接地、低於 1.5 m、離開半徑 60 m、過度混入其他軸旋轉或超轉，都會使當前橫滾證據失效；回到足夠高度及區內後，重新準備並完成一整圈。
- 先前 checkpoint 里程碑可保留，但不允許中斷後省略新的倒置／一圈，直接靠回平取得通關。依目前提示及本圈進度操作。
- 墜毀、Disarm、失焦／斷線、Reset、時間倒退、資料中斷或位置跳躍會停止本次練習。「再練一次」會清空本次步驟，從地面重來。
- 「橫滾練習數值」顯示本圈進度、實際橫滾速度及機身傾角；高度與 XYZ 仍顯示。回放讀取該段錄影的姿態與獨立判定進度，暫停時固定。
- 新 `full-roll` 使用獨立課程 ID 與規則 6，初始沒有 L10 成績；不把 L00 觀念示範或已核准 L09 的紀錄轉算為完成。

## 集中人工核對

- 選課及示範工具列是否都有 L10，並能從實際地面自行起飛。
- 看示範時是否能辨識準備、倒置、完成一圈與恢復；每一段都能跳看、暫停及往回拖曳。
- 能否分別用左滾或右滾完成；倒置／停止旋轉及油門提示是否容易理解。
- 只左右傾斜、半圈翻回、偏航或前後翻轉時，是否保持未完成整圈。
- 成功時是否仍在空中；接地或過低中斷後，是否要求重新準備與完整動作。
- 重載是否保留 L10 成績及次數，且舊課程紀錄不變；示範是否不增加次數。
- 高度、進度、旋轉速度、字幕與步驟是否同步，暫停／換鏡頭是否仍可讀。
